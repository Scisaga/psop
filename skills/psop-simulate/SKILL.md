# PSOP Simulate：交互装配环境

入口为现有设备工作台的 **Simulate 模拟**。先确认设备工作区和知识版本；需要了解验证范围时读[实施状态](references/implementation-status.md)，修改状态或服务时读[会话与 API](references/contracts-and-api.md)。操作与渲染设计见[装配环境设计](../../docs/simulate/simulate-design.md)。

## 高优先级：装配判定与设计保真

**不能把刚性网格交集直接作为装配的否决条件，也不应为了消除交集就认定需要移动或修改原设计。** 已有原装关系中的微小接触重叠默认允许虚拟连接，保留几何测量；弹性、过盈、预紧及补偿按各自机制解释。材料参数或变形求解器缺失不直接禁止装配编辑，不要求逐条先完成力学认证。完整规则见[共同判定规则](../../docs/architecture/assembly-judgment-policy.md)。普通 `connect` 已分别保存几何观测、操作资格和未计算力学状态，重叠不直接锁住连接。

## 使用与维护

- 每条 DKP Part 生成一个独立场景实例，来源参考装配不自动建立会话连接。已有方案固定工作区、快照和包摘要。
- 初始库存按网格包围尺寸选择低高度的平放朝向，同高时优先让实际来源三角片组成的较大边界平面朝下，再优先接近来源朝向；薄片、加强板、PCB、连杆和轴承不能直接沿用整机竖装朝向。朝向确定后重新排布并落桌，保留 18mm 间隔和 0.2mm 台面间隙。这是显示布局启发式，不是重力／稳定性认证。新建和显式 `reset` 应用该布局；加载、复制和还原历史不重排用户已保存的位姿，不修改 DKP 和参考装配。
- 默认操作整个连通组合；`Alt＋点击`或成员列表查看内部部件。选择后，兼容对象／组合所有可见成员显示金色发光轮廓，选中对象显示浅蓝轮廓，移除常驻接口点。拖近时同时检查成员间实际空间距离（8–20mm）与画面间隙（6px），不能仅因投影重叠跨距离触发；180ms 展开、1.35 倍退出，移远立即关闭，鼠标进入卡片不锁定。松手后悬停预览，**点击已就绪的连接方式直接提交，局部放大接口展示连接动画，然后回到原视角**。`Esc` 跳过展示并到达已保存终态。
- 检查当前 DKP 的全部接口，联合读取通用匹配、原装参考及已发布修正配置。接口详情逐项列出关联对象；无匹配或无终态保留明确原因。未指定实际选孔的参考关系不能擅自选择全部成员。全量核对入口为 `npm run audit:simulate -- --geometry`。
- 连接以具体成员部件和接口为端点。移动应用于整个被拖拽组合，固定目标组合，保持所有组内相对位姿。
- 接口 ID 独占，并核对实际成员引用的底层资源、共享孔道和替代特征。隐藏对象不释放占用。
- 服务端重新核对修订、候选、占用和整组终态，位姿、连接与保存一次提交。预览和取消均不改状态。刚性几何结果与装配操作资格分别解释；当前策略与检查范围见[实施状态](references/implementation-status.md)。
- 已检查终态但缺少连接件或保持依据时，允许带条件的试装；照常占用接口，保留来源姿态、成员对应和待补条件。动画不提供装入路径或物理保持结论。
- 选中组合后，点击模型接口处的“拆分”标签（详情栏“连接”也可操作）。解除指定连接后，较大子组合留在原处，较小一侧按整组包围盒寻找最近的桌面空位并抬起归位；数量相同保留原连接目标侧。归位保留内部相对位姿，避让所有库存（含隐藏对象）、工具和台面边界；无足够空位时保留当前位置并提示。若仍有其他连接路径，只解除该边，不移动模型。解除和归位作为一次操作保存、撤销及重做。
- 左下角提供“恢复初始拆散状态”图标：`reset` 解除全部连接、释放占用，按固定 DKP 恢复初始位姿，保留场景身份／名称和历史。整次重置只占一步，可撤销／重做并跨刷新保存；不自动删除场景或改 DKP。
- 左下恢复、自动组装和选择提示使用同一横向工具栏，窄窗口收起提示，不能各自绝对定位到相同位置。自动组装先读取 `/health` 的 `simulate.commands`，确认服务支持 `auto_assemble` 后才保存草稿及发出命令；更新后要核验用户原来使用的服务端口，不能仅验证另开的预览端口。
- 左下“自动组装”使用 `auto_assemble`、`mode: reference`，按用户选择执行成品参考演示。先比较来源关系、实际成员和相对位姿，保留正确组合，拆开与目标构型不一致的连接，再分步还原方案所选构型；新方案默认来源原装，几何协调为可选工程推断。明确成员的参考接口仍独占；缺少实际机械接口时仅使用来源模型刚性节点／父子关系建立 `source_structure` 参考边，接口为 null，不虚构孔位或占用。新增连接全部标 `reference`、`geometry: not_evaluated`，不冒充实体检查通过。普通连接与参考还原共用所选全局构型，终态几何与操作资格分别记录。
- 自动组装在服务端一次保存完整终态、参考标记和一步历史，客户端按服务端发布的 `waypoints` 重放，不能重新猜测来向或加通用弧线。直接在当前工作台播放，保留原视角、导航和工具；左下紧凑进度控件提供暂停、1×／2×／4×、跳过及可选“跟随装配视角”。鼠标旋转、右键平移和滚轮缩放始终可用，开始操作立即关闭相机跟随；视角按钮和聚焦不能终止装配，结束保留用户视角。Space 暂停／继续，Esc 跳过，失焦暂停，减少动态效果直接显示保存结果。按用户要求不在界面显示待核工艺提示；内部 `reference_handoff`、来源与检查结果仍保留，不伪记物理通过。
- 检查全部部件的装配过程：从成品反向搜索退出方向与阻挡，倒序生成安装依赖；跨来源节点的部件可先在独立工位组成子组合，再整组对接。空间整理逐件执行、避让当前库存；转运采用组级包络、足够高度的旋转和障碍绕行，最后按已检查退出路径逆向入座。轴承入口只能来自已发布环接口的轴线成员，最后一段同轴且不旋转。下方入口和嵌套子组合预留抬高工位，不能仅凭部件类型决定先后，也不要求所有轴承在全机第一步一次装完。
- 常驻工作线程用完整来源网格的有限表面采样及实体射线检查移动，原装接触深度单独保留；再以实际播放函数复核所有路径段的中间姿态和台面。采样无异常不等于连续碰撞检测完备、力学或工艺认证。没有有据可依刚性路径的来源包覆／软质关系使用显隐交接示意，不能让不透明实体穿越障碍，不能推定材料应变或修改设计。现 Microduck 有 5 个此类步骤，内部明确标记，界面只显示安装进度。正确但封闭且阻挡工序的组合可临时打开，合回时保留原连接 ID；临时打开与错误连接分别记录，无关正确组合保持刚性。
- 金色和浅蓝轮廓的打包深度纹理使用 RGBA8；不能用半浮点格式存储 RGBA 字节深度，避免可见边缘误判遮挡。检查多视角连续轮廓及真实遮挡，不能仅验证候选 ID 集合。
- 撤销、重做恢复完整位姿和连接，保存最近 100 步。复制方案继承内容并清空历史；不同知识版本分别管理。

Simulate 使用全视口沉浸布局，左上方案胶囊、右上视角／画质／全屏、左侧工具条、选中即显示的右侧小信息卡和右下统计。信息卡展示名称、成员／连接数、可用接口和兼容对象数；`/` 打开临时对象目录，信息卡按需展开变换、接口、候选和连接工具；浮窗不挤压视口或重置相机。连接卡片固定底部居中、毛玻璃、最多三种默认方式，以实际可见视口固定底缘并限制高度，不测量内容高度反推顶部；列表内部滚动、标题与底栏不收缩，异步检查及矮窗口下也完整显示。目录和接口关联可主动浏览远处目标，下一次移动恢复距离关闭；连接特写期间淡出 HUD，完成恢复。环境按 Tony Stark’s Workshop 私人研发空间组织，长方形平面与局部斜窗带，保持少量精细设备。保留一组仪器桌、桌沿夹持的橘黄色任务灯和一台 CAD 衍生六轴机械助手；不放车辆、装甲、圆台、成排货架、红色工具箱或主台灰绿色灯。移除的台灯不再占用自动归位位置。墙板、窗框、钢梁与吊灯有实际厚度、收边和连接；地面与墙体分别使用本地 4K／2K PBR 材质。高／均衡画质提供低强度粗糙平面反射，房间静态阴影排除移动 DKP 模型；流畅关闭附加反射。设备是展示环境，不进入库存或装配检查。“工坊”查看整体空间，“透视”回到装配视角，均不进入历史。资产及许可见[环境记录](../../apps/workbench/src/assets/private-workshop-source.json)，模型来自 Poly Haven CC0 和 ROS-Industrial Apache-2.0，本地服务附带署名与许可。完整资源就绪后才开放场景，切换时取消旧加载并释放纹理、ImageBitmap 和 WebGL 上下文。交互预览使用默认浏览器或原生窗口视口；`--headed --keep-open` 禁用固定视口模拟，固定 1920×1080 仅作性能采样，另验真实窗口客户区。选择、相机、显隐和画质不进入装配历史。

两侧窗外使用同一滨海研发园区的配套视图：一侧为低层研发楼与树冠，另一侧为海湾与远山，光照及地平线协调。每侧整条窗带共用连续外景，按源图比例铺设在窗外，玻璃使用低不透明度物理材质；不逐窗重复、不拉伸建筑。外景随本地资源加载、重试和释放，标注真实位图分辨率及生成提示词。机械助手使用连续来源坐标的 PBR 材质区分涂装、金属圈、接口与针脚；保留 CAD 顶点和面片，不用逐三角形配色制造材质边界。展示法线可以平滑曲面，但须保留接口硬边；环境显示调整不修改 DKP 或已有方案。

方案菜单的“参考构型”仅改变后续目标，不移动现有位姿；“按此构型还原”才执行自动组装。构型、装配策略设置进入一步历史、复制和原子保存。重叠细节默认折叠，显示实际体积和有范围的采样深度；不把工程推断混入安装方向选项。

## 实现入口与验证

- 页面：[SimulatePage.tsx](../../apps/workbench/src/SimulatePage.tsx)，三维操控：[SimulationCanvas.tsx](../../apps/workbench/src/SimulationCanvas.tsx)。
- 状态与连接图：[simulate-core.mjs](../../apps/workbench/scripts/simulate-core.mjs)，服务与保存：[simulate-store.mjs](../../apps/workbench/scripts/simulate-store.mjs)。
- 几何进程池：[simulate-geometry.mjs](../../apps/workbench/scripts/simulate-geometry.mjs)，复用 Build 的完整实体检查内核。
- 自动装配计划：[simulate-auto-assembly.mjs](../../apps/workbench/scripts/simulate-auto-assembly.mjs)，演出与镜头：[SimulationCinematic.ts](../../apps/workbench/src/SimulationCinematic.ts)。
- 轴承预装单元与入口：[simulate-bearing-sequence.mjs](../../apps/workbench/scripts/simulate-bearing-sequence.mjs)，轴向转运及入座：[simulate-motion.ts](../../apps/workbench/src/simulate-motion.ts)。
- 全件工序与路径：[simulate-assembly-process.mjs](../../apps/workbench/scripts/simulate-assembly-process.mjs)、[转运编排](../../apps/workbench/scripts/simulate-process-optimize.mjs)、[来源网格采样](../../apps/workbench/scripts/simulate-path-geometry.mjs)、[回放复核](../../apps/workbench/scripts/simulate-process-audit.mjs)，由[独立工作线程](../../apps/workbench/scripts/simulate-process-worker.mjs)执行。
- 在 `apps/workbench` 执行 `npm run test:simulate`、`npm run test:simulate:real`；浏览器验收执行 `npx playwright test --config playwright.simulate.config.ts tests/simulate.spec.ts`。
- 实测与截图见[验收记录](../../docs/simulate/verification.md)。性能记录须注明实际硬件、浏览器、窗口和画质，区分首次 DKP 完整校验与持续交互。

首版提供装配编辑、终态几何和有限采样的过程检查。连续装入路径的完备认证、变形、重力、摩擦、碰撞反弹、关节动力学、承载验证和模型测试尚未实现。旧查询 CLI 已移除，不作为装配环境入口。
