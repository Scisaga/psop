# PSOP Simulate v2

2026-11-06（Asia/Shanghai）。先读[共同装配语义](../../docs/architecture/assembly-interfaces.md)和[当前能力](references/implementation-status.md)。Simulate 消费固定 DKP，方案、尝试和会话保存在包外，不改写设备知识。

## 请求与能力

核心请求为 `query(A,B,context)`：返回有依据的方式、选孔、对端映射、连接件要求、共同构型、局部作用与未决条件。先固定知识修订、起始配置、允许的机制和连接件范围、已有关系及工程／Task 条件。

能力规则、具体选择／绑定、操作过程和实际状态遵守[共同一致性规则](../../docs/architecture/assembly-interfaces.md#9-规则绑定操作和显示的一致性)。已有参考解不是唯一解；静态孔道、未绑定紧固路径、角色链和真实运动轨迹分别读取，不能互作路径通过或已接合依据。

当前共享逻辑只提供有界选择和刚性孔组匹配查询；完整机械动作、连续路径、变形、渲染、模型执行和训练回流尚未实现。`doctor` 报告实际能力，`query --help` 查看当前输入参数。旧 core、build／serve／fixture／replay 运行入口不恢复。

```powershell
python -B skills/psop-simulate/scripts/psop_simulate.py doctor
python -B skills/psop-simulate/scripts/psop_simulate.py query --help
```

有功能定义的受控夹具使用显式 definition 输入；真实设备使用已验证 DKP 与具体 Part。1.4～1.8 可读取 Build 已发布的安装孔位、功能说明、组合规则和参考安装映射，固定其来源与适用配置；这是静态设备知识查询，不宣称穷尽新构型的安装方案。1.3 或未提供功能说明的部件仍返回几何及缺项，不把空结果称为无法安装。合成定义仅验证规则，不作为 Microduck 安装许可。

1.6 还读取全对筛查、逐对连接审查、有限开口／内腔和补全示意。查询需说明双方局部位置、定位与保持角色、中间件、运动归属、替代解释及缺项。厂商通用资料、项目推断及用户原话分别保留；小柱用途不能延续旧用户确认标签。synthetic 补全螺钉或压盖不是已确认设备物料，其显示和展开也不创建实际接合状态。

1.7 的 pin_hole_fits 只支持来源共同配置中的安装定位用途推断，保留有限插入、径向间隙及双方身份；参考两成员不生成最少数量或允许子集。轴向保持和承载仍 unknown，外侧共轴大洞用途未知。补全件 usage=reference_connector 仅为已有参考路径的未绑定连接件；unverified_alternative 不进入当前保持角色，轴心螺钉／压盖归此类、默认不显示。禁止由配合、动画或示意件生成已固定标签；1.0～1.6 按冻结合同读取。

## 选择、匹配与试装

- 安装孔位／作用角色身份固定，方式以 S 参数选择成员；同一孔道的两侧孔位分别寻址、共享底层占用。完整允许集合、数量范围、同侧邻接、包含锚点和成对条件分别表达，未知批准集合不当作封闭白名单。
- 孔入口与实体柱按实际类型读取，柱不要求 hole_ref。来源只确认位置时，机制和组合约束保持 unknown，不从另一孔组补默认双孔规则。qpos0 相位差不等于所有构型不可安装；源轴线吻合也不等于已保持。
- 标准孔位映射由 Build 随 DKP 交付，按参考配置读取，不把来源模型中的标准连接重新归为全未知。运行中的实际接合集合 E 与参考选孔 S 分开，参考关系不自动创建已紧固状态，也不锁死其他安装方式。
- 所有选中孔及作用面共用一份刚性位姿或一致内部 q。保留对称映射，不按 ID 或原始姿态硬选唯一答案。
- 对端映射、实际第三件与未绑定角色分开。没有螺钉或承接依据时报告缺项，不生成虚构 Part 或已保持状态。
- 操作方向须引用具体绑定、进入侧、承座／目标、Frame 和假设；不得直接沿用几何轴线、孔口进入方向、角色名称或显示偏移。沿途有限作用段和整体构型按具体机制共同核对，穿层件、沉头、旋转锁止及卡扣不套用统一直线双孔模板。
- Build 记录或示意图的方向仍须在其声明范围内检查；重放通过不替代物理正确性。历史 1.7 连接件示意存在方向缺陷；1.8 仅核验显式装入假设下的有限几何一致性，不能作为自动动作输入或方向真值；缺资料标未知，缺计算能力标未支持，不用理想固定补齐。
- 查询建议可按工程和 Task 筛选；自由试装评估用户指定的其他组合。物理受阻、工程不符、任务错误、知识未知及计算未支持分别返回。
- S 是选定路径集合，不是已接合集合。各 path 的进入、保持和完成独立，整体按方式派生。已成立的作用不因任务错误或其他路径未完成而消失。
- 同一接口可用 AB 接 X、CD 接 Y；按实际区段和 SHARE 规则检查冲突，不设置整个接口 capacity=1。一根螺栓穿多层与两根争用同段不同。
- 选孔／映射／参与者改变后，冻结绑定遵循新的连接身份及局部连续性；用户的一次交互尝试可以包含多个配置快照。

终态匹配不等于从当前状态可达，拆卸也不默认是插入反向。刚体碰撞不替代卡扣变形模型。舵机输出孔组与壳体孔组不能因同一 STL 而默认刚性绑定。未实现的检查返回未评估，不通过动画或理想固定补造真实作用。

## 后续场景与模型测试

场景、相机、批量视图和模型测试使用统一工作台底座；Compile 可提交生成计划并管理审核及数据用途。模型只读规定观察，隐藏对象身份、求解答案和 Task 状态只供监督与评测。模型建议仍经同一动作检查，不能直接写入当前机械状态。

工作台的参考位姿、爆炸、透明和剖切属于浏览。详情见[设计](../../docs/simulate/simulate-design.md)和[运行合同](references/contracts-and-api.md)。

1.8 参考连接件的 insertion 保留外侧入口、头下基准、杆向、目标与有限壁段；finite_geometry=pass 只说明显式假设的图形一致，连续路径未评估、保持未知，不成为实物方向或装配完成标签。
