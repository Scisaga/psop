# Simulate v2 编排流程

1. 在统一工作台选定设备工作区与固定 DKP，核对模型、来源及能力范围。
2. 区分用户意图：装配实验、场景观测／视图生成，或已登记模型测试。
3. 固定所需对象、配置、相机、任务参数、模型与环境。缺少输入或执行器时报告具体 unavailable，不生成假结果。
4. 新执行器接入后，交互与批量任务都通过受控服务运行，保存作业、状态、验证范围与产物引用。
5. Compile 消费有血缘的观测候选，审核、划分后发布数据集；模型版本再交给 Simulate 测试。
6. 失败、未知与人工纠正经审核形成后续版本，基础事实修订返回 Build，冻结包与历史评测不改写。

当前没有 v2 模拟执行器。不要运行旧发行物、旧 SQLite 或旧命令作为替代。界面中的来源参考、爆炸、透明与剖切只服务浏览。

见 [技能入口](../SKILL.md)、[运行边界](contracts-and-api.md) 与 [系统设计](../../../docs/architecture/system-design.md)。
