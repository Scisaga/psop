# 装配监督合同 /1

适用于读取 `psop.assembly-assessment/1` 的语料设计与审查。当前没有样本生成或训练执行器；本合同不表示已经生成数据集或训练模型。

每条装配观测分别保存以下字段，不合成一个“通过/失败”标签：

| 字段 | 内容 |
| --- | --- |
| provenance | DKP 摘要、来源网格 SHA、方案 ID/revision、选用构型、策略摘要、观测算法版本 |
| geometry | 原始 `clear/interference/unresolved/not_evaluated`、体积、交集分量、位置及有范围的深度采样；未计算留空 |
| relationship | 原装关系 ID、实际接口与成员、声明/来源/工程推断依据；来源结构边与机械接口分别表达 |
| operation | `allow/allow_with_note/block`、理由及独立失败见证；允许操作不改写 geometry |
| mechanics | 变形、应力、保持、承载的实际求解状态；缺参数时为 `not_evaluated` |
| target | 监督任务及其范围：几何观测、虚拟操作、关系恢复或经独立验证的物理结论 |

必须执行以下审查：

1. `geometry=interference` 不自动生成不可装配、误装、设计错误负例；材料/变形未计算也不生成负例。
2. 虚拟操作负例须有独立的错误尺寸、错误成员、资源冲突、闭环不一致、台面或新增无关障碍见证，绑定当次策略和构型。不得仅引用正交集体积。
3. `operation=allow_with_note` 只支持虚拟操作标签，不等于刚性无交集、物理保持或承载成功。
4. 工程推断协调姿态与来源姿态均保留身份；交集变小不能把协调姿态设为唯一正确答案。来源预紧、补偿及自由状态不能被隐式归入错误标签。
5. 深度字段标注采样方法、坐标系与范围，不能把 `2V/S`、包围盒厚度或有限采样最大值标成精确最大穿入深度。
6. 历史 /2 刚性筛查产生的排除项按原范围解释。迁移时重新评估操作资格，保留原始几何和包摘要；不得批量变成机械负例。

例如，头壳在来源姿态约 `67.9 mm³`、协调姿态约 `0.00305 mm³` 的交集，可以同时具有 `operation=allow_with_note` 和 `mechanics=not_evaluated`。这两条记录不是谁对谁错的物理监督对。
