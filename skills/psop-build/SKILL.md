# PSOP Build

当前合同、Schema 和发布操作见 [v2 合同](references/v2-contract.md)。执行接口识别、原装补漏或兼容分析时，读取[接口分析与验收](references/interface-analysis.md)。历史包保持原字节和原规则。

## 高优先级：装配判定与设计保真

**不能把刚性网格交集直接作为装配的否决条件，也不应为了消除交集就认定需要移动或修改原设计。** 将弹性让位、过盈、预紧、软接触及制造或装配补偿纳入解释；已有原装关系中的微小接触重叠默认支持虚拟装配。材料或应力数据缺失不直接构成禁用理由。几何观测、操作资格与力学验证分别记录，具体规则与依据见[共同判定规则](../../docs/architecture/assembly-judgment-policy.md)，优先于下文历史刚性筛查口径。

## 先发现本件能力，再解释参考装配

先读取适用 AGENTS.md、实际输入和正在运行的包。已有几何测量和原件可以复用，不能把检测结果数量当成装配理解。

原始网格是几何发现的输入；已有目录和原装关系作为可归因的功能及参考覆盖层。独立要求只用于验收，不能把其中的坐标、孔数和预期类型喂给发现器。逐部件完成：

1. **本件有哪些有限结构？** 检查任意轴向孔、实体柱、内外锥面、阶梯、有限面、入口和非圆区域；记录局部坐标、原三角见证、测量质量和未支持残余。用途未知的几何仍发布。
2. **它们能承担哪些作用？** 将功能已确认的接口与几何潜在模式分开；定位、导向、承托、保持、传动和运动归属分别说明。一个接口可以包含孔壁、柱、肩面和键槽。
3. **原装接口分别连接哪里？** 结合原始位姿、装配树、有限几何和资料，建立双方接口及实际成员的连接图。逐个安装结构给出处置：已知原装对端、原装未使用、缺件/缺细节、用法未决或原配置冲突。发现遗漏就继续查原件、剖面和可得资料并补充；已有目录只是部分基线。
4. **哪些新配法合理？** 按版本化机制检查所有异来源实例对，依次核对功能互补、完整成员、共同刚性变换、功能间隙、有限重合/支承及整件干涉。新配法搜索独立于原装距离、对端清单和世界位姿。需要紧固件、活动相位或其他条件的，分别保留条件。
5. **原装配合是否被兼容分析识别？** 对每条有依据的原装关系，以双方接口及已指定成员核对结果。未识别时追查尺寸规则、成员组合、台阶段、落座分支、实体干涉、源冲突或未支持机构，并记录证据和具体缺项。部件对出现不代表具体原装接口已经识别；已知冲突也不能批量升级为兼容。

逐件输出安装结构、功能接口、原装图和兼容核对清单。用途明确的接口以定位、支撑、限位、紧固、传动或导向解释必需/可选成员；新几何假设经有证据的功能资格审查后可参与完整接口匹配。每处疑似安装结构都要有去向。只要还有用法未决、未支持结构或无法解释的原装漏报，就明确缺项和范围，不能声称所有实际安装结构已找全。

同源网格可共享测量，实例身份、功能、活动归属和规格仍分别绑定；来源模型出现多少次不等于已确认实物库存。先核对独立截面与正反例，再发布覆盖结论。

## 接口、几何和连接

- 不同作用端、入口侧可为独立接口并共享有限物理资源。连接绑定双方接口和实际成员；对端暂缺的接口继续保留。轴承内外圈、有限壁面和端面分别解释。
- 组合规则来自声明或结构依据，相邻关系按真实布局定义；矩形间距与节圆不互换。孔组成员数、连接实际选孔和螺钉数量分别表达。
- 源模型合并活动件或静态相位未齐孔时，检查缺少的运动框架和安装相位，记录简化边界，保留已有依据支持的接口。
- 身份使用所属部件、固定语义键和源几何修订；名称、排序、浮点显示和证据文案不作身份。跨源修订明确版本。
- 原装用途、对端身份、几何状态与紧固细节分别表达。用途与对端已明确时，紧固规格未知不抹掉其依据；几何偏差仍单列。历史假设逐条核实并进入跟进清单，新兼容装法不自动关闭原装未决。用户新确认新增证据，不改写厂商或历史几何证据。

## 有独立依据时合理修正参考数据

上游仿真位姿或简化模型可包含自由状态、预紧、弹性让位及补偿偏置。存在交集或移动后交集减少，不足以认定参考位置错误。有独立定位、尺寸、坐标映射或设计依据支持错误时，在用户已授权的任务范围内主动合理修正，不重复要求确认。

- 优先求满足配合约束的最小刚性调整；有共同承座的相关件一起检查，避免移好一个件却移坏其对端。通用算法不写设备名、固定坐标或统一的“0.2 mm”阈值。
- 每次冻结独立的修正预算、计算容差、来源 SHA、有限几何引用、依据和邻近约束；数值精度、工程可接受重叠及位姿修正预算分别表达，不篡改求交测量。
- 保留原始来源和几何，发布单独的**工程推断修正配置**，记录前后位置、差值、逐项验证及采用理由。配置选择遵循用户选择及发布约定，不因交集减少自动改选；相关连接采用一致配置。原配置的观测不能冒充修正配置的当前状态，也不能仅凭刚性重叠否定原设计。
- 复核相关孔轴、有限壁段重合、承托面和已有定位关系；相互矛盾、超出预算或缺少实体材料时不得强行吸附。未知保持与载荷不抹掉已经支持的几何配合，也不因此编造工程通过。

本版 `--reference-adjustments` 使用 [reference-adjustments/1](schemas/reference-adjustments-1.schema.json) 输入，在 prepare 中执行有见证的最小平移，freeze/validate 重放验证，finalize 只打包。旋转或几何修补需要采用相应验证方法，不把此平移方法冒称为任意装配求解器。实施依据见[参考装配合理修正](../../docs/reference-assembly-repair.md)。

## 证据应简短、具体、可定位

保留来源修订、SHA、实际位置及所支持的具体结论。用户装配声明、原模型配合和项目推断分别标注；厂商通用图只支持其展示的机构。

只记录影响当前判断的未知项和冲突。没有螺纹模型不抹掉已知安装用途；实际尺寸不相容要指出哪两段、差多少。查阅过但没有支持结论的资料不进入接口支持证据。材料、过盈、粘接、螺钉规格、预紧与保持工艺没有依据时不补造。

不要求每条关系填满角色、研究动作、替代解释和缺证数组。调查过程留作研究产物，日常 DKP 和操作界面不重复承载整篇调查报告。

## 发布精简结果

1.15 将本件有限几何、资源/入口、潜在模式、功能证据和来源参考连接分层。`scene.assembly` 是浏览摘要，完整部件详情和跨件候选按索引分片读取；客户端不重新猜接口或把候选提升为已连接。

跨件候选先保留位姿无关的局部几何必要条件，再按捕获的完整接口规则资格筛选。转子端盘所有四孔须由同一刚性关系同时对应；不得降为单孔、任意双孔或从不同侧别和接口拼凑。对端额外备用孔可由有结构依据的显式有效子组参与，不能任意取孔。明确声明的相邻双孔规则继续有效，完整孔组不等于安装四颗螺钉。

测量/配准误差、功能间隙和实体求交精度分别说明。局部承托、滑配、插入和紧配采用有依据的各自条件；不能对所有机构套用统一半径差。保留真实台阶段和入口分支，只合并有见证的等价别名。非圆、复合接口和未解自由度逐项报告支持范围，不把已遍历接口数当成已经完整求解。

捕获规则、完整匹配、局部线索和失败姿态分别发布。孤立孔、普通面接触及没有功能依据的大径向容纳保留为线索，不计入默认完整接口候选。历史 /2 匹配策略只发布刚性 clear 姿态；新 /3 匹配策略发布完整接口的虚拟操作资格与原始求交结果，允许带重叠或未计算状态的试装。过盈、柔性及预紧规则可以声明有依据的负名义间隙，仍检查完整成员和尺寸。客户端严格重放发布的 R/T，不另加间隙或按包围盒移动零件。

当前刚性执行器只将空交集或全部交集分量局限于数值精度薄层的结果记为 `clear`；开放或无法解释的实体记为未评估。保留这些几何结果，装配资格另按共同判定规则解释，不要求先把正常过盈或微小接触重叠改成 `clear`。有限分支失败不代表物理不可能，也不代表全部连续装法。策略字段、入口、执行器和数值精度见[接口分析与验收](references/interface-analysis.md)。标准件只记录有依据的参数需求；明确选择成员后显示参考路径示意，不补造 SKU、实际数量或未知长度。

按 `prepare → freeze → finalize → validate → register` 发布。`prepare` 执行发现、参考覆盖与全对候选生成；`freeze` 核对独立要求、完整分片及工具/输入摘要；`finalize` 只发布封存字节，不新发现知识。输入或工具变化须重新 prepare/freeze；旧包不原地改写。设备坐标和验收样例只放设备数据。

## 验收实际任务

几何、功能接口、原装用法和兼容核对分别验收。从独立原三角、截面、多视图和功能资料检查逐实例安装结构，承槽、挡面、导向与夹置面也须有成员和见证。独立原装基线绑定全部实例、源 SHA、配置、必需接口、具体成员映射、有限面及观察处置；捕获方法见[接口分析与验收](references/interface-analysis.md)。不能从新生成结果反推期待数量。

删除接口、关系、成员、必需面片或审查处置后须失败，重算统计/摘要不能掩盖。漏整孔、漏台阶、误合并盲孔或相反入口、混淆轴承内外圈均须失败。功能别名直接指向有见证的测量片并共享资源，不增加实体材料。重放只证明可重复，不能替代独立几何和原装正反例。

候选验收覆盖随机来源位姿不变、半径反例、功能间隙、公差未知、跨层轴向偏移、台阶段分支、对称、手性、分页续跑和全部实例对/模板处置。四孔对六孔缺少有效子组依据时保留局部线索；有明确有效四孔子组时验证完整匹配。缺一孔、错孔距、跨接口拼凑须失败，原相邻双孔规则不受破坏。独立原装正例查漏报，错配与穿透反例查误报；不能以候选数量或同一生成器重放代替。

实际打开工作台，检查：找接口、选择成员/允许组合、定位本件、定位正确对端、返回、打开具体证据。普通选择不移动相机或自动切换透明；局部查看可恢复。查看最终画面，检查窄面板、首次数据量、切换延迟及空闲渲染开销。

交付实际包版本/摘要、独立覆盖、候选边界、性能与缺项。固定两件贴合的实体干涉检查与连续装入路径、保持、承载、活动子框架和多部件变体求解分别声明；后几项仍属后续 Simulate，不以浏览动画表示已经通过。

合同与设备实例见 [v2 合同](references/v2-contract.md) 和 [装配接口规则](../../docs/architecture/assembly-interfaces.md)。
