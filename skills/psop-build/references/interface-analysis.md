# 接口分析与验收

用于接口发现、原装补漏和兼容分析。入口流程见 [SKILL.md](../SKILL.md)，Schema 和发布操作见 [v2 合同](v2-contract.md)。

**优先遵循[装配判定与设计保真](../../../docs/architecture/assembly-judgment-policy.md)。** 刚性求交是几何观测，不能直接否决装配或强制修正原设计；下文已发布策略的通过与排除限定于其刚性筛查范围。

## 从有限结构形成接口

先核对原三角见证，再解释作用。检查孔道连通、台阶、凹凸材料侧、入口、安装面、承托区域及轴向止挡。同轴不证明连通；两耳、相反盲孔和不同活动件不能只凭轴线合并。

| 作用 | 核查结构 |
| --- | --- |
| 定位与传动 | 孔轴、台阶、非圆轮廓、键槽及运动框架 |
| 支撑与限位 | 有限承座、端挡、侧肩和夹置面 |
| 紧固 | 完整孔组、允许选孔、头部/螺母座及连接件条件 |
| 必需与可选成员 | 有来源的组合规则；额外备用孔单独标注 |

方向分组和重复孔检测产生几何假设。资格升级须捕获用途依据、必需成员、原三角/资源引用和适用机制，核对组合的物理意义。工程推断可成为附条件接口；没有依据的结构继续保留线索，不能以“此前未登记”为拒绝调查的理由。

## 原装连接图

图的边绑定双方接口、实际成员、机制、配置和证据。空成员列表表示选用细节未给定，不表示已用全部成员。原始位姿是线索；轴线、有限接触、孔组与安装作用提供验证。来源简化、螺纹和实际夹紧未知与用途/对端身份分别表达。

从独立三角观察逐实例检查邻接与所有疑似安装结构，每个观察给出处置。requirements/2 的 `reference_uses` 捕获 [reference-use-review/1](../schemas/reference-use-review-1.schema.json)，锁定全部来源实例、源 SHA、配置、必需接口、具体成员映射及有限面区域。已有目录只是部分基线。

用法未决时继续查可获得的几何、资料、截面和邻接约束，记录具体缺失证据。静态相位、活动框架与源模型冲突分别处置。不能以通用“保持未知”代替可查清的定位或对端。

连接可附带 [reference-connection-assessment/1](../schemas/reference-connection-assessment-1.schema.json)，绑定配置、依据及用途、对端、几何、紧固四项状态。`identified` 表示有依据识别用途或对端；`axes_aligned` 只确认所选成员的源孔轴对应，不代表整件无干涉或已安装螺钉。轴线结论须通过来源位姿下完整成员的一一对应复核。具体未决项写入 `open_items`；不能把原 `hypothesis` 批量改成已紧固。

新构建的 policy/2 设置 `reference_review_schema=psop.interface-analysis-review/2`，使全部未决假设、源冲突和分项待核进入 `followup_required` 及按原因统计。兼容恢复仍独立统计 `compatibility_followup_count`，一个新装法通过不关闭原装用途调查。没有该字段的旧包继续重放 review/1，保留原封存语义。

## 完整模式和尺寸

四孔须由一个 proper rotation 和 translation 同时满足；反射不能通过手性检查。额外备用孔的有效子组须明确成员和依据，不能任意取四孔或跨接口混合。

分别记录测量/配准误差、功能间隙和实体求交精度。局部承托不同于完整轴承座；名义留隙的承托关系保留实际接触、包围和轴向保持的限制。没有功能依据的大径向容纳继续属于局部线索，不能通过统一放宽阈值升级。

一个物理孔可含多个有限台阶段。等价别名可去重，真实壁段分支应保留，不能按 Feature ID 字典序选择一段。所有选段共享完整孔组的刚性变换及同一落座条件。

## 新旧策略与输入

历史 `psop.interface-matching-policy/1` 保持原规则。新构建可捕获 `psop.interface-matching-policy/2`，保留原有完整孔组、相邻双孔和实体检查，并支持：

- `member_selections`：每项绑定 `interface_ref`、`allowed_member_sets`、`statement`、`evidence_ref`。成员必须来自同一接口；不能缩减 `required_patterns`。
- `radial_fit_rules`：每项绑定一个接口、适用 `mechanisms`、`fit_kind`、`radial_clearance_m`、`statement`、`evidence_ref`。范围表示名义 female-minus-male 半径差，规则不指定对端白名单。未声明规则仍执行名义配合检查。
- `interface_qualifications`：绑定几何假设的 `interface_ref`、全部 `member_refs`、`mechanisms`、`purpose`、`statement`、`basis=engineering_inference|source_document` 及 `evidence_refs`。核对有限见证与证据后参与声明机制，不改原始几何假设或建立原装连接。

间隙规则的 `fit_kind` 为 `clearance_fit` 或 `partial_radial_support`；前者保留制造配合等级未知，后者另保留局部接触、完整包围和保持限制。仅改策略也需新建 DKP 修订。

`coverage.interface_analysis` 逐项报告功能资格、非圆/复合约束支持情况和原装关系在兼容结果中的处置。核对具体接口及已指定成员，部件对出现不能计为识别。`interface_pattern_search_complete` 表示声明策略已执行；`interface_matching_complete` 还要结合未支持结构说明。

只读核对已有包：

```powershell
python -B skills/psop-build/scripts/review_interfaces.py --dkp <package.dkp> --output <local-review.json>
```

此报告发现已登记接口与发布结果的不一致，不独立证明所有源安装结构已发现，也不自动升级原装缺项为兼容。

## 固定姿态与实体检查

有限端部对位是一种落座方法。单轴仍有自由转角；有限枚举失败不代表连续空间中的物理不可能。需要安装面、肩面、非圆轮廓或活动框架的约束须有对应方法与见证，未支持时明确列出。

当前实体执行器是固定版本离线 Manifold WASM，许可、来源与 SHA 位于 `scripts/vendor/manifold-3d`，全部进入工具摘要。Node.js 22+ 或 `PSOP_NODE_PATH` 提供执行器。方法为 `closed-source-solid-interference/2`，数值接触允许量为 `3e-7 m`；只有空交集或所有交集分量局限于该精度薄层时记为 `clear`。开放或无法解释的实体记为未评估。这些是现有刚性几何结果，不代表装配资格；保留真实测量，工程可接受重叠按连接机制另行处理，可使用体积及局部深度阈值，不通过篡改计算精度把结果伪记为 `clear`。

每个通过方向保存精确 R/T、有限选段、落座及实体检查见证；失败或无法判定分支保留在 `placement_exclusions`。客户端严格重放，固定终点通过不建立装入路径、保持、承载或多件求解结论。

参考螺钉只消费明确连接的 `fastener_paths`，绑定双方接口、成员、壁段和 low/high 入口。实际选择成员后才显示，不因打开四孔接口补造四颗螺钉；示意件不进入来源 Part、物料数量、SKU 或未知长度。

## 原装与兼容的核对处置

| 结果 | 处理 |
| --- | --- |
| 双方接口及已指定成员被识别 | 记录候选引用及验证范围 |
| 同接口只有其他选孔成立 | 记录差异，追查原装成员或活动相位 |
| 完整模式成立，刚性求交存在重叠 | 保留几何观测，结合弹性、过盈、预紧、补偿及具体接触区域解释；不直接否决装配或改原设计 |
| 非圆、复合或活动框架未支持 | 列出具体接口、成员和方法缺口 |
| 只有局部几何线索 | 查尺寸、组合、台阶段和功能资格 |
| 原装假设或原配置不相容 | 保留原依据；新装法不否定原配置冲突 |
| 无法解释 | 保持开放并继续调查 |

每条有依据的原装关系进入核对分母，按 basis 分别统计。未知或未支持的处置表示暴露了问题，不表示已经识别成功。原装正例与错孔距、缺孔、经独立证据确认的异常穿入反例独立于生成器；刚性网格重叠不自动构成装配负例，重算摘要或重放不能代替。

运行包按需加载部件/部件对分片。同源测量、别名和重复姿态证明可共享，实例功能身份分别保留。大篇研究过程与调试日志另存；运行包保留可复核结论的输入与见证。交付四类覆盖、具体缺项、修复样例、包版本与边界。
