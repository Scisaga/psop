下一步缺项
1. 先选定目标候选，固定真实输入知识修订、当前配置、机制/连接件允许范围、环境及已有占用，明确工程和 Task 条件。
2. 绑定实际存在、可追溯的连接件 Part，提供每条孔路径的 fastener、承接与有限作用区/区段依据；不能自动发明螺钉。
3. 获得各条选中路径的进入、接合、保持和完成证据；所有选中路径完成的方式才可派生整组完成。
4. 补齐装配/拆卸可达路径、弹性接合、载荷、工程与任务检查。现有 CLI 缺这些执行器，需要另行接入相应模型或实测流程；再次 query 本身不能认证完成。

歧义与失败
1. 夹具有七个声明 mode，但 query 只选择 exact-four-examples；CLI 没有 --mode-a/--mode-b 选项。因此本产物不覆盖全部七个 mode 或所有 mode 组合。“可能的安装方式”若意指它们全部，技能没有明确提供遍历流程。不能把本次 complete=true 扩大成全部声明模式或真实安装机制均已穷尽。
2. 技能要求固定起始配置等上下文，但本夹具 context={}，且 CLI 只读取文件内 context。本次可明确声明为空上下文，不能得到当前真实状态或可达性结论。
3. Windows PowerShell 首次 Get-Content 未加 -Encoding UTF8，中文显示乱码；改用 UTF8 后全部可读，文件未修改。
4. 一次辅助汇总脚本把 assessments 写成 assessment，出现 KeyError；改成正确复数字段后完成汇总和 schema 验证。该失败未影响已成功生成的原始查询产物，未发现产品 CLI 执行失败。
