# Microduck 装配接口验收

2026-11-08，工作台 `http://127.0.0.1:8780/`。本次先核对源装配、原三角及厂商结构资料，再修改目录和代码；未改动原 STL、孔径、拓扑或历史包。

## 实际装配判断

| 对象 | 接口及组成 | 当前连接解释 |
| --- | --- | --- |
| XL330 | X−、X+ 端盘各 4×Ø1.6，PCD12 | 两个独立端盘能力；厂商区分驱动端和 Idler Horn，合并 STL 尚未给出 ±X 与 Front/Back 的可靠对应 |
| XL330 | 壳体 A/B 各四孔，16×30 矩形，孔道共享 | 每侧任选相邻两孔；0820 实例的腿连杆对应 B2+B3。矩形不再误标 PCD34 |
| 左、右髋 | 源 X/Y 各一组 4×Ø2.4、PCD12；各一处 Ø16 外圆与轴肩 | 四孔连接端盘；外圆/轴肩支承轴承内圈。目录分别保留四个部位，不顺带全选 |
| 右脚—右脚底 | 脚下侧壁、环形台阶及横肋，对应杯状脚底的内壁、杯口及内底 | 包覆套合、承托；没有依据补造胶粘、过盈、TPU 或脚底倒扣 |
| 右脚—右踝 | 两个卡钩/台阶与中心阶梯孔 | 卡钩及中心螺钉夹持假设；卡钩不是脚与脚底之间的连接 |
| 右髋俯仰轴承 22×16×4 | 内孔两端分别对应舵机 Ø16 端盘外圆和髋 Ø16 轴颈；髋肩承内圈、加固板端面承外圈 | 源几何给出轴向叠层；PCD12 螺钉走轴承孔内，不穿过滚道。实际螺钉、预紧及外圈径向保持仍待核实 |
| 右踝轴承 15×10×3 | Ø10 内孔对应腿连杆轴颈，Ø15 外圆对应踝部承座及肩面 | 不直接套到 Ø16 舵机外圆；尺寸不相容的对端单列排除 |

其余部件也按“已有装配接口—有限组成—可能能力”逐项复核。最终 70 实例中 69 个已有具体接口记录；扬声器源模型只有 12 三角盒体，无法从该代理确定真实安装结构。头部偏心/干涉、未知选孔子集等保留具体说明。

## 组织与交互

`scene.assembly` 与 `knowledge.assembly` 保存同一目录：539 个精选有限特征、193 个接口、104 条连接。成员绑定实际源 SHA 与三角；连接引用具体接口和选用成员，Part 对只用于查询，不承担唯一身份。共同孔壁可共享资源，功能侧仍分别存在。

已删除旧安装、假设、审查、调查面板和客户端猜部位逻辑。新发布路径不运行全 Part 对搜索，不携带旧分析数组、模板报告或原件全文。证据入口按当前结论绑定实际记录，原件按需加载，长文本每页 160 行。几何坐标按需展开。

选择只改局部高亮；定位才进入明确提示的临时本件查看。对端定位使用实际接口及成员，返回恢复原选择和相机。关系没有指定成员时不自动全选。平面/曲面定位使用原三角面积法线，孔入口使用向外观察方向。曲面承托成员只高亮已记录的原三角见证，不将整片内底冒充已经证明的接触面积。
