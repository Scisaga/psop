# Microduck alpha 设备说明

本包选用官方软件明确支持的 **alpha + Radxa Zero 3W + imu_to_dxl v2** 配置，电池按同一控制设计中的 **NP-F550**。下列已记录型号用于统一设备描述；没有完整料号和数量依据的项目不补猜采购规格。

![官方整机照片](官方整机照片.jpg)

照片为官网外观参考，不能从照片确认内部装机版本。Microduck 是小型双足机器人；其身体、腿、颈和头部通过舵机关节运动。

| 部件 | 本包采用的配置 | 官方依据与精度范围 |
| --- | --- | --- |

| 关节舵机 | 15 个 Dynamixel XL330 系列 | [总线实现](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/duck-control/src/bus.rs)、[关节表](关节名称与ID.md)；未确认准确子型号，不补写后缀 |

## 主控与传感器接口

以下均来自同一官方软件提交；连接器或控制器名称是软件说明，不能代替完整线束、供电和装配图。

| 关系 | 官方软件定义 | 来源 |
| --- | --- | --- |
| Radxa → HAT 的 I²C | 40 针排针的物理针 3 为 SDA、针 5 为 SCL；使用 I²C3 M0，400 kHz | [Radxa 接口配置](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/deploy/audio/i2c3-pihat.dts) |
| HAT 音频接口 | I²C 地址 `0x18` | [同一接口配置](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/deploy/audio/i2c3-pihat.dts) |
| HAT 头部 IMU | BMI088；加速度计 `0x19`、陀螺仪 `0x68`；由 `tofd` 读取，默认关闭，可配置启用 | [头部 IMU 定义](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/tof/src/imu.rs)、[采集程序](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/tof/src/main.rs) |
| HAT 测距接口 | 测距模块通过 HAT 的 J5 接入 I²C；软件支持不等于每台机器人均已装配，不指定未确认的采购型号 | [接口配置](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/deploy/audio/i2c3-pihat.dts)、[操作速查](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/docs/robot/cheatsheet.md#the-tof-sensor-tofd) |
| 主控 → 舵机与身体 IMU | `/dev/ttyS2`、1 Mbps；15 个舵机与身体姿态板共用总线，身体 IMU ID `200` | [运行配置](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/deploy/robotd.toml)、[身体 IMU 定义](https://github.com/pollen-robotics/microduck/blob/4861141fdc7c7acd253671acf5abdd55b77b779e/duck-control/src/imu.rs) |

头部 BMI088 与身体 LSM6DSV16X 是两个位置和接口均不同的传感器，不是两套整机方案。这里没有给 HAT 指定制造修订版或芯片位号，也没有推定整块板能凭 40 针接口直接互插。 独立的 [HAT C1 板级资料](../04-HAT板级BOM与电路/README.md)可用于查板上元件与电路，但尚未确认对应本页 alpha 整机，不能据此将 C1 列为已确定的整机采购件。
