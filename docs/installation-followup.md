# 原装安装补录与七项未决的复核结果

2026-11-09。发布版本 `2.0.0-capabilities.5`，摘要 `3955ee11502b1d0c926243de719d00f4bba3b811db9c75f7a9f8608be50edc6a`。此前[全量审查](original-installation-audit.md)发现的四处漏登记均已补录；原有七项也已继续追查到具体有限结构、对端或仍缺失的输入。

本轮新增 14 项功能接口和 7 条参考关系，现有 257 项功能接口、145 条参考关系。70 个实例、38 份源网格、原实例位姿及既有 20 条头部参考修正约束均保留。接口会共享同一原孔壁或曲面资源，14 项不能解释为 14 处新增物理紧固。

## 已补录的四处漏项

| 部件对 | 新增内容 | 依据与限制 |
| --- | --- | --- |
| 左髋连接件 ↔ 轴承支承片 | 两端各一组双孔接口，一条具体关系 | Ø2.05 / Ø2.2、18 mm 中心距、孔段间隔约 0.2 mm；与原有 16 mm 舵机壳体孔组分开。紧固件与夹紧仍未验证 |
| 右侧对应部件 | 同上 | 镜像源孔壁逐一核对 |
| 头部驱动侧轴承 ↔ 电机支架 | 一项局部承座及一条外圈参考关系 | Ø22 / Ø22.2，有限轴向重合约 3.4 mm，支架曲面覆盖约 101.8° |
| 头部对侧轴承 ↔ 电机支架 | 另一项局部承座及关系 | 保留下壳原承座；局部承接不能解释为完整包围或轴向保持 |

四处新增 6 项接口、4 条关系，原曲面和双方选用成员均纳入独立要求。源网格尺寸不作为制造公差。

## 原有七项的逐项结论

| 原未决项 | 本轮核实和补充 | 仍需的输入 |
| --- | --- | --- |
| 左外壳 | 竖向 Ø2.2 通过段 / Ø5 凹孔对应躯干左髋偏航舵机 B 侧 `hole_front_top`；原轴线一致。补录壳体接口和单个指定接收位 | 实际紧固件与安装路径属于后续装配验证；这项用途和对端已定位 |
| 右外壳 | 镜像孔对应右舵机 B 侧 `hole_rear_top`，来源位姿横向偏心约 **0.5 mm**；以冲突关系保留，并可查看冲突对端 | 需要独立核定外壳参考位置，未修改源位姿 |
| 眼环 | 三凸耳与面板三个通槽一一对应。凸耳半径 8.5–9.5 mm、20°；槽半径约 8.45–9.55 mm、20.6°。实际原多边形轮廓有正间隙，凸耳长 1.5 mm、板厚 1.3 mm。补录两端接口和三组映射 | 直槽定位已明确；轴向防脱工艺仍缺失，不能称为倒钩或旋转锁止 |
| 香蕉形 PCB 锁扣 | 将两处板件定位耳与两端 50 mm 安装入口分开编目。现有主控和 HAT 均在头部，不是此躯干锁扣的对端。社区香蕉电源板仅作用途背景 | 原被锁持板的板框、厚度、孔槽及保持过程未提供 |
| M12 镜头座 | 保留 Ø2、20 mm 中心距双孔；新增 Y=12 mm、轴 Z 的径向 Ø2 紧定入口用途推断。官方 `.part` 元数据标识镜头与座为独立导出件，70 个实例没有独立相机传感板 | 相机板对端孔组，以及径向紧定件和螺纹规格未提供；不以树莓派主控板替代 |
| 头部偏航轴承 | 重核既有内圈关系；遍历全部有限圆柱，在声明窗口内没有找到 Ø22 外圈承座。Ø18 内圈轴肩不能当作外圈承座 | 外圈接收面及轴向挡面仍未确认；可能缺失的部件或残余曲面用途不能由检索补造 |
| 扬声器 | 原文件只有 12 个三角组成的六面体；贴靠舵机的位置可复现，官方元数据也确认其扬声器身份。检查的社区资料没有提供与当前包络匹配的固定结构 | 真实安装几何和螺孔、卡扣或其他固定工艺仍缺失 |

七项均有新的逐项调查记录。当前逐实例审查中有 6 个部件保留具体未决问题，其中右外壳是位置冲突、眼环是防脱方式未决。这个数量不表示其余部件都已完成实物装配验证。

两侧舵机的单孔接收位与既有壳体四孔组共享同一原孔道。四孔组仍遵守原相邻双孔选择规则；专门的单入口只记录这条外壳孔道，不代表单点固定整个部件的工程资格。

构建按 `prepare → freeze → finalize → validate → register` 发布新包，未改写旧包。新源结构、成员对应、有限面见证及来源 SHA 均进入独立验收；不是只更新总数。全部实例的平面观察审查基线保留，新增曲面和槽的用途由本轮有限见证单独补充。

专项回归覆盖镜像双孔的 18 mm 间距、两个 101.8° 局部承座、原四孔选择规则、0.5 mm 源错位、三凸耳与实际通槽边界、缺失板件不被无关板卡替代，以及删除新增孔组/承座后验收必须失败。工作台还保留冲突对端的查看与定位，来源冲突不会被显示成已确定安装。

实际界面核对还修正了两处显示问题：以曲面中心描述的接口按真实原面片可见性选择局部视角，带明确入口的成员保留自身方向；原几何记录沿已声明的来源替代映射显示功能接口关联，避免同一原孔壁在功能页已补录、几何页仍显示用途未知。关联受部件归属和源 SHA 约束，未按相似尺寸合并。

仓库和工作区只保留 `.5`；旧 `.4` 包已删除，共 172,247,786 字节。历史审查 JSON 和截图继续保留，常规维护和当前测试使用 `.5`，不依赖旧包。
