2026-11-09，Asia/Shanghai。检查对象为当前唯一登记的 `2.0.0-capabilities.4`，摘要 `69f6ee2e13b4051f6f42522639f77459081b83e9b95d4b5ea5b99c48324fe0e4`。

**结论：尚未全部识别。新确认四处原装配功能接口漏登记，按两端接口组织建议补录六项；原有七项用途或对端未决继续保留。** 四处指四个部件对，几何证据支持补录有归属的安装能力与待验证参考关系，不表示四个已完成实物工程验证的接合。

这次工作是只读审查，没有改写源网格、作者输入或不可变 DKP，也没有把邻近观察自动登记为连接。当前工作台中的接口数量仍为已发布的 243 项功能接口。

圆孔、圆柱与圆锥的源核算使用已公布径向拟合残余、数值预算，以及“小梯度被表示为圆柱”时丢弃的半段径向变化量；这些预算不代表制造配合公差。平面邻近与孔道轴线窗口只是查疑计算范围，不能作为物理安装验收标准。

70 个实例的完整接口清单、已登记关系、关节桥接及圆形结构观察见 [inventory.json](../build/original-installation-audit/inventory.json)。原三角平面证据见 [planar-review.json](../build/original-installation-audit/planar-review.json)。本轮逐件浏览器记录见 [ui/audit.json](../build/original-installation-audit/ui/audit.json)。

已有功能用法合同仍[校验通过](../build/original-installation-audit/contract-validation.json)，返回的状态为 `reviewed_declared_scope_with_explicit_open_items`。它重放已声明的独立要求，不负责发现未列入要求的新安装结构，因此没有捕获这四处漏登记。当前包全部 2,571 个登记资产的字节长度和 SHA 再次核对一致，审查过程中未修改包。

## 其他观察的处置

- 舵机与电源支架存在同轴孔段，需要结合中间底座核实整条紧固叠层；没有据同轴性新增双方直接固定关系。
- 电机支架与头部上壳的 Ø18.4 / Ø19 局部弧面名义径向留隙约 0.3 mm，导向或避让用途需核实，没有据此新增固定关系。
- 左侧外壳的竖向孔与躯干舵机有一条同轴几何观察，仍归入现有外壳用途未决；没有将它当作已用紧固孔。
- 原审查其余无登记部件对中的光学窗口、活动喙部、软质口部邻边及小面积外壳邻面，以及放宽窗口新增的 0.3–0.6 mm 邻近，均保留为几何观察。具体用途与保持缺少依据时不补造安装关系。
- 既有关系内的倒角、相接孔段或附加曲壁不单独累计为新的功能接口。它们也不因此被认定实际参与安装。

原始配置的冲突处置与当前修正配置分开读取。应用已发布修正后，138 条关系中有 37 条假设、4 条声明、85 条源几何配合、8 条修正推断配合、2 条源装配和 2 条排除记录；这不是 138 条已确认物理固定。

## 复现

在仓库根目录运行，输出均位于 DKP 之外：

```powershell
python -B device-materials/assembly/audit_original_installation.py
python -B device-materials/assembly/audit_reference_surfaces.py `
  --output build/original-installation-audit/planar-review.json --maximum-gap-mm 0.6
```

在 `apps/workbench` 目录核对实际界面：

```powershell
node scripts/capture_reference_uses.mjs --out ../../build/original-installation-audit/ui
node scripts/capture_installation_audit.mjs
```

首次两项为来源、目录与几何复核；界面检查证明已发布内容能显示，不能替代新结构的识别。后续补录应将新孔组、两侧局部承座及其原三角见证加入独立安装要求，再发布新修订；不能只重算数量使旧清单通过。
