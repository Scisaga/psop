# Compile UI 参考资料

v2 的正式产品入口是 [统一工作台](../../../apps/workbench/README.md)。同一设备工作区中的 Compile 组织语料、训练实验、模型与评测，并与 Simulate 场景和知识对象定位。

本目录 SVG 与旧 [apps/compile](../../../apps/compile/README.md) 页面属于前版视觉研究，不是当前路由、数据合同或能力证明。旧静态曲线、预测、权重元数据和对话样例不能迁入真实设备工作区冒充运行结果。

新的界面保留已认可的紧凑工作台原则：连续面板、细线分区、独立滚动、明确选中态和真实空状态。设备、知识快照、场景、数据、模型和评测版本由工作区统一组织，界面不再以每个 DKP 内的独立 App 交付。

产品责任与当前实现边界见 [Compile 设计](../compile-design.md) 与 [系统设计](../../architecture/system-design.md)。
