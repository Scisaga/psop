# v2 规范十四视图：共享场景执行与 Compile 数据管理

> 2026-11-05（Asia/Shanghai）。本页是目标合同，真实生成器与监督发布尚未实现。旧“生成、登记、覆盖与验证全部由 Compile 自带渲染器完成”的职责表达退出当前架构。

## 1. 职责

统一工作台中的 Simulate 能力负责组织场景并提供渲染入口；共用场景／渲染底座执行交互与批量任务。Compile 根据模型目标创建生成计划，管理用途、标注审核、划分和数据集登记。两个入口使用同一受控配置和结果。

视图可以针对单个部件、部件组合或固定设备配置。来源有专属实物几何时才声明对应实物；其他情况仍为模型域观察。不同视图不增加部件身份或类别。

## 2. 输入条件

开始生成前明确设备知识版本与摘要、对象集合、来源几何、单位和变换、规范方向的依据、场景配置、执行器和用途范围。方向猜测保留候选，不冒充确认的正面／上方。无实际网格、不完整视图或 AI 补图不能标为规范十四视图。

包内浏览场景不自动具有训练或监督能力；实际生成与数据发布以相应 capability、执行报告和审核为准。

采用右手坐标：+X 为右，+Y 为后，+Z 为上；前为 -Y。表中向量表示从目标中心指向相机的方向，执行时归一化。

## 4. 结果与验证

每组保存输入知识快照、对象／配置、源文件与摘要、变换、场景与相机参数、执行器版本、profile、种子、输出清单、文件摘要、成功／失败及覆盖报告。缺方向、状态变化、逐图尺度跳变、错误绑定或不可复验时不发布完整十四视图声明。

RGB、mask、框、深度、法线、位姿、可见性分别登记通道、单位和检查状态。知识关系不自动成为视觉关系真值；不可见对象和关系保留观测不足。生成包不得伪装为实拍。

## 5. 数据划分与当前状态

同一来源 CAD、配置、组合和场景家族的视角与派生图必须同组划分。十四视图只提供基础覆盖，仍需受控增强、真实照片和独立真实测试。

当前 Build 源模型包仅提供浏览索引，training_data 为 unavailable；工作台中的生成和模型测试能力尚未连接执行器。旧线框生成器、静态 UI 样例或人工截图不构成 v2 生成器验收。
