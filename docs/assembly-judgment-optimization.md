# 装配判定优化：执行与验收

2026-11-11。按已确认的全链路方案实施。高优先级依据见[装配判定与设计保真](architecture/assembly-judgment-policy.md)。

## 交付行为

- 原装参考关系支持直接连接，包括约 `0.00305 mm³` 的微小接触，以及来源构型中约 `67.9 mm³` 的头壳重叠；真实测量保留为 `interference`。
- 新方案及自动还原默认来源原装。几何协调为可选工程推断；所有参考关系从同一套全局位姿生成，头壳的闭合面和三点闭合不会混用构型。
- 切换构型只改变后续目标，不移动已有方案；“按此构型还原”才执行自动组装。现有方案通过保存设置、参考报告或一致的连接引用推断构型，保留原有位姿。
- 几何观测、虚拟操作资格及力学状态分别保存。材料、应力或变形未计算时允许带说明试装，不要求逐条认证。
- 选孔、完整成员、功能尺寸、资源占用、闭环及台面约束继续校验。无关障碍按新增或加深的实质穿入见证判断；已经存在且未加深的接触允许保留或退出。
- 几何详情折叠展示；轻微接触只留记录，不显示红色禁用提示。原装参考、工程推断和试装分别表达；构型不混入安装方向。

## 阈值和记录

原装接触先返回体积观测与操作资格，展开详情后按需测量深度；采样未完成仍保留已测体积并可连接。

方案策略默认接触显示筛选 `0.01 mm³`，无关障碍采样深度门槛 `0.1 mm`。它们是可配置的编辑处理参数，不是制造公差或材料极限。原数值接触精度 `3e-7 m` 保持。

`geometry` 保存原状态、体积及双件观测；`assembly_assessment` 保存 `allow/allow_with_note/block`、理由、构型与策略摘要；`mechanics` 保存未计算状态。独立的选孔或闭环问题仍可返回外层 `unresolved/blocked`，重叠本身不映射为否决。

深度记录是有限源表面采样的最近三角距离，不是精确最大深度。每个见证包含 A 局部坐标、源三角和对端三角，交集分量另存体积及包围范围。未计算保留未计算，不使用 `2V/S` 或包围盒厚度冒充深度。

Build 刚性结果缓存绑定双件源 SHA、R/T、数值算法及诊断版本，核验固定内核字节和缓存内容摘要。缓存不包含操作资格；策略通过共享函数单独评估。Simulate 操作缓存再绑定包、会话修订、候选、构型和策略摘要；未计算结果不长期缓存。
