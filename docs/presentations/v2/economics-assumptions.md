# 设备服务全生命周期价值核算

对应主幻灯片第 15 页与[参数模型](economics-model.json)。Microduck 识别与复检用于说明任务，客户规模与成本需按真实设备业务另行取得。所有基线、归因、成本及计算结果保持空值。

| 价值域 | 改善机制 | 计量与凭证 |
| --- | --- | --- |
| 交付准备 | 关联部件、配置、适用版本与操作依据，减少重复资料整理与适配 | 可比型号准备工时；配置与验证记录；新增审核成本 |
| 现场效率 | 对齐部件位置、工具反馈与下一步骤，减少重复查找和等待 | 操作工时、设备状态、任务与等待原因；计入补证与人员指导 |
| 服务质量 | 在相同完成条件下比较复检、远程指导、返工与更换路径 | 可比故障与服务工单、实际费用、全部成功及失败路径 |
| 知识复用 | 复用经验证知识、EG、反馈轨迹、适配模型和评测 | 后续适配工时，扣审核、维护及版本更新；首次建设另列 |

## 成本与归因

可归因的避免支出 − 新增检查、指导与验证成本 − 平台建设与运行成本。

工时、设备可用时间、周期与现金分别核算。固定薪酬与折旧不能直接视为节约现金。平台成本包含数据、标注、软件工具与接口接入、任务验证、训练、终端、计算和持续维护。

同一工单与凭证只入账一次；若总服务成本已含复检和指导费用，净现金贡献中不再次扣除。比较同类任务与故障严重程度，保留失败、返工及负增量。设备释放时间在缺少实际利用证据时不折算收入。

## 客户收益与平台经营

客户侧衡量可比操作与服务任务的净变化。平台侧可通过设备任务软件、领域模型持续服务及设备接口适配取得收入；价格和履约成本需由实际合同及记录验证。直接贡献为确认收入减可归因交付现金成本，计入固定运营支出后才能计算净利润。

现有机械臂 Runtime 实验验证任务机制，经济收益仍需独立取得基线和归因。Microduck 是设备示例，不能由单台演示推出厂商级节约或收入预测。必要操作检查、设备兼容测试和验收条件继续计入成本。
