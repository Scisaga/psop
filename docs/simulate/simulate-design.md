# Simulate 三维装配工作台

2026-11-11。首版在现有 PSOP 工作台提供可持续连接、拆开和保存的装配环境。运行与验证范围见[验收记录](verification.md)，机器接口见[会话与 API](../../skills/psop-simulate/references/contracts-and-api.md)。

## 装配判定（高优先级）

**不能把刚性网格交集直接作为装配的否决条件，也不应为了消除交集就认定需要移动或修改原设计。** 已有原装关系中的微小接触重叠默认支持虚拟连接，保留测量；弹性、过盈、预紧和补偿按各自机制解释。缺材料或变形求解不直接禁用装配编辑。完整规则见[装配判定与设计保真](../architecture/assembly-judgment-policy.md)。普通连接已将刚性观测、操作资格和未计算力学状态分开保存。

## 页面与操作

Simulate 使用独立的沉浸布局：三维视口铺满工作区，共享导航及常驻对象树、详情栏在此页收起。左上角悬浮胶囊保留返回工作台、方案菜单及保存状态；方案菜单管理新建、复制、重命名和固定知识版本。全局工作台其余页面沿用原布局。字体和矿物青交互色保留，悬浮控件改为石墨灰毛玻璃。

环境参考 Tony Stark’s Workshop 的私人研发空间，采用 **7.6×8.4m 长方形平面、直线端墙与局部斜窗带**。布局只保留中央 DKP 装配台、后方双屏仪器桌和一台六轴机械助手；台灯夹在后方桌沿。不放车辆、装甲、圆台、成排货架或红色工具箱，主装配台上的灰绿色台灯已移除，其台面保留区同步释放。

建筑采用有厚度和倒角的混凝土板，接缝有凹槽；窗框包含金属框、密封条和连续窗台。顶梁包含腹板、翼缘、端板与螺栓，吊灯包含金属灯罩、内衬、卷边与连续吊杆。地脚收边、吊顶板和嵌入式通风口同属建筑结构，避免悬空杆件。

两侧窗带展示同一滨海研发园区的配套外景：一侧为低层研发楼、树冠和山坡，另一侧为海湾与远山，保持一致的日光和低饱和色调。两张本地生成图均为原生 1774×887，每侧窗带共用一张连续画面，按源图比例设置窗外平面；物理玻璃保持轻微反光和透光，避免逐窗重复或拉伸建筑。

中央桌架保留四根连续方管腿、闭合上框、水平下框、调节脚和避让桌腿的置物板。后方仪器桌保留一台示波器和两块实体工程屏。橘黄色任务灯使用完整网格、UV 与 2K 材质，底部安装销对准桌沿的 C 型夹具套筒；夹具具有上／下夹爪、压紧螺杆和压力垫，实际夹持桌板。机械助手采用 CAD 衍生的六轴几何及发布关节原点，使用固定展示姿态与中性涂装；不参与拾取、库存、连接检查或历史。

机械助手的底座面板区分哑光涂装、金属螺栓与边框、深色凹入接口及针脚。连续来源坐标驱动 PBR 颜色、金属度和粗糙度，微细粗糙度经过导数过滤，材质边界不沿三角面着色。曲面平滑保留面板和接口硬边，原始 CAD 顶点坐标与 40,020 个面片保持不变。

地面与墙体分别使用本地 **4K 颜色、2K 法线及粗糙度材质**。地坪使用 2m 实际纹理比例、2.4m 低对比伸缩缝和封闭涂层的粗糙度变化；伸缩缝在材质内进行导数抗锯齿。实体地面保持不透明，高画质增加 1024 像素的低强度粗糙平面反射，均衡采用 512，流畅关闭附加反射。墙体单独配置纹理、比例和细法线，源位图保持不变。

照明保留局部装配阴影；房间设备使用另一套静态阴影，仅缓存环境模型，排除会移动的 DKP 实例，防止拖拽后留下旧影。画质切换同步调整房间阴影与地面反射，静止时不重复绘制。没有雾、景深模糊、环绕城市背景或四周拉伸图片。

右上“工坊”以较宽视角查看整体空间；“透视”回到装配视角，视角变化不进入撤销历史。环境、来源、实际分辨率和许可见[环境记录](../../apps/workbench/src/assets/private-workshop-source.json)与[模型来源记录](../../apps/workbench/src/assets/workshop/models/source.json)。任务灯来自 Poly Haven CC0，机械臂来自 ROS-Industrial 的 Apache-2.0 包，许可与署名一并随本地服务提供。资源准备脚本为 `apps/workbench/scripts/prepare_workshop_assets.py`，运行页面无需访问外网。

装配台面仍为 Z=0，地面 Z=-0.76m。全部本地纹理与模型完成加载后才开放操作；失败可重试，切换方案会取消旧请求，释放迟到的模型、纹理、ImageBitmap、反射目标与 WebGL 上下文。

初始场景每条 DKP Part 创建一个实例，按实际包围尺寸选择较低的平放朝向；同等高度时优先让来源网格中较大的边界平面朝下，再选择与来源朝向相近的方案。薄片、加强板、电路板、连杆和轴承不沿用整机中的竖装姿态。朝向确定后重新计算包围盒，以 18mm 间隔排布，底部距台面 0.2mm。此朝向是库存展示启发式，不是重力或稳定性求解；不修改 DKP 网格、来源位姿、接口和参考装配，也不自动建立会话连接。加载和复制已有方案保持保存的位姿；新建或显式恢复初始拆散状态才使用新布局。

左键选择，移动超过 4px 开始沿台面拖拽；松手保存一次移动。空白处左键旋转相机、右键平移、滚轮缩放。拖拽期间关闭相机操作。默认操作整个组合；Alt＋点击或成员列表查看内部部件。移动／旋转控件支持轴向约束，详情栏输入毫米及角度。

| V／W／E | 选择／移动／旋转 |

## 连接流程

1. 选中部件或组合，右侧自动显示紧凑信息卡，按当前剩余接口检索兼容对象。兼容对象的所有可见成员使用金色发光轮廓，选中对象使用浅蓝轮廓；移除常驻接口点。描边深度使用匹配 RGBA 打包的 8 位纹理，避免半浮点舍入把可见边缘误判为遮挡；真实被挡住的边缘仍隐藏。读取中明确显示检索状态。
2. 拖动或变换后，逐个比较双方真实成员的世界包围盒和当前视角投影凸包；不以整组包围盒中间的空区触发。空间间隙需同时满足随尺寸变化的 8–20mm 阈值、画面间隙不超过 6px，不能仅靠投影重叠跨越远距离触发。停留 180ms 展开，退出使用 1.35 倍阈值，越界后立即关闭。仅选择时先描边提示。
3. 多目标优先当前指向对象，再按实际间隙排序；当前目标仍邻近时保持，切向另一个指向对象需停留 360ms。鼠标进入或聚焦卡片不锁住距离判断。兼容对象目录、接口关联入口和目标切换可主动查看远处对象；下一次移动会恢复距离判断，远离时照常关闭。
4. 默认展示三种方式，更多可展开；每种方式提供孔组、成员数、方向和检查状态。紧凑毛玻璃卡片直接固定底缘，距实际可见视口 20px，高度不超过 350px，并扣除顶部控件与可见区域的遮挡；不用当前内容高度反推顶部位置。异步检查和展开只改变内部滚动区域，标题与底栏不收缩、不越界；保存后的重新检索保留当前候选。
5. 悬停显示半透明终态与接口对应；**点击已就绪方式直接提交，成功后放大接口，播放整组刚性连接动画，然后准确返回展示前视角。Esc 跳过时到达已保存终态并恢复镜头**。不增加第二次确认。
6. 被占用、台面穿透、纯示意或缺少可用终态的方式说明具体原因；错误位置、尺寸或无关部位穿入按具体证据判断。刚性网格存在交集不独立成为禁用连接的条件，可接受重叠保留检测记录。默认使用来源原装构型，几何协调为可选工程推断。

连接固定目标组合，整体移动来源组合，保持各自内部关系。单件、组合使用同一套候选与命令。提交经过服务端复核，刷新中断动画时仍恢复已保存的终态。悬停和取消不修改装配状态。

缺少标准连接件或保持依据时，已通过终态检查的方式可以建立带条件试装；试装照常占用接口，连接工具保留待补条件。

## 连接图、占用与拆开

### 自动组装演出

“自动组装”按用户确定的“成品演示优先”方式工作：目标为 DKP 已发布的来源／修正参考构型。服务端比较来源关系、明确接口成员和当前相对位姿，保留正确组合，删除与成品参考不一致的连接；逐组移动时保持原组合内部关系。成品按真实包围盒居中并落在台面，不修改 DKP。

自动装配直接在当前工作台播放，保留原有 HUD、视角与全尺寸视口，左下仅显示紧凑进度。鼠标旋转、右键平移、滚轮缩放始终可用；可主动开启“跟随装配视角”，按参与包围盒及遮挡选择特写，鼠标操作或视角按钮立即恢复自由观察，不能终止装配。Space 暂停／继续，提供 1×／2×／4×，Esc 或跳过显示已保存成品，结束保留用户视角。失焦暂停，减少动态效果直接显示终态。待核工艺提示按用户要求不显示，内部记录保持真实。结束后保留小信息卡，拆分标签在主动点选模型／打开连接工具后出现。

全部件从目标构型反向搜索退出路径，结合真实网格的有限表面采样及实体射线观察阻挡；倒序形成安装依赖，需要预装时建立来源子组合及独立的抬高工位。轴承轴线来自已发布环接口的具体成员，最后一段直线入座且不旋转；转运逐件执行，以当前库存包络规划绕行，在高处旋转后沿检查过的路径逆向入座。整组保持刚性，正确封闭组合只在确实阻挡时临时打开，最终保留原连接 ID。来源接触深度和新的途中穿入分别记录；限形／软质关系缺少刚性工艺依据时使用内部标注的参考交接。客户端重放服务端路径，不另加弧线；提交前复核实际播放函数的所有路径段中间姿态。有限采样不是连续路径完备证明，也不修改原始设计或冒充材料／力学验证。

该演出与普通试装的资格分别表达。可用的已发布参考接口仍执行占用互斥；缺少实际接口依据时，仅用来源模型刚性节点或父子层级建立注明来源的结构参考，空接口不占孔道。所有新增参考连接标记“参考 · 待核”，不声称实体检查通过。当前 Microduck 的 70 个部件可形成一个参考组合，其中若干连接仅由来源结构支撑；已知微小干涉保留，不通过演出抹除。

终态、连接、参考报告和历史在播放前原子保存；演出只是呈现这份结果。中途刷新、跳过和网络重试不会留下半成品或重复连接。整次装配一步撤销／重做，复制及重新打开保留报告。继续手动移动、连接、拆分或 reset 会清除“成品参考就绪”状态。

左下角“恢复初始拆散状态”图标解除当前全部连接，按固定知识版本重新计算初始排布，保留场景身份和名称，显示全部部件并回到全场视角。位姿、连接和资源释放原子保存为一步历史；失败保留原状态，重复请求返回原结果，撤销恢复重置前完整装配，刷新后仍可撤销。

部件为节点、连接为边。组合是连接图的连通分量，接口和共享孔道占用由当前连接派生。每个接口同时只能参与一条有效连接；检查实际成员的共享资源、替代特征和别名，不允许换入口绕过占用。

选中组合时，接口附近显示带引线的“拆分”标签，可直接点击解除一条指定连接。标签避让工具条、视口边缘和相邻标签；连接过多时保留详情入口。解除后重算分组，较大子组合留在原处，较小一侧按整组包围盒找到最近的桌面空位，保持朝向及内部相对位姿，播放抬起、平移、落下的归位动画。相同部件数量保留原连接目标侧；搜索避让其他所有实例（含隐藏对象）、工具保留区和台面边距。无足够空位时保留原位并明确提示。若仍有其他连接路径，只删除连接，不移动模型。拆分与归位属于一个完整历史步骤。同组补充连接只检查当前构型一致性，不自动移动内部成员求闭环。

撤销、重做恢复完整位姿与连接，最近 100 步跨刷新保存。场景自动保存到 DKP 外；多个方案独立，复制继承当前内容并清空历史。不同知识版本分别管理，不自动迁移。

## 终态几何与资格

几何检查、装配操作资格和力学状态分别表达。已有原装关系与微小可接受接触重叠允许保留原配置进行虚拟装配，不要求先改几何或取得有限元结果。可按连接机制配置重叠体积、局部深度与接触区域阈值；不得将允许操作伪记为刚性求交 `clear`。

### 当前实现

普通连接保留真实求交结果，使用共享操作策略判定。原装及合格接口接触允许连接；错误成员、资源、闭环及台面仍阻止，无关部件须有新增或加深的采样穿入证据。

所有接口均从当前部件详情读取；同时消费通用模板匹配和带配置引用的原装参考连接。已发布修正参考配置独立提供选项，保留原始姿态。选孔未指定的参考关系保留入口并注明缺项，不能自动选择全部孔后提交。没有已发布匹配或可用终态的接口仍显示在详情中，注明当前知识限制。


复用 Build 的完整接口匹配、成员映射、精确旋转与平移。移动组与其他所有场景实例先做包围盒筛查，再由两个常驻 Node/WASM 进程执行完整实体检查。额外检查覆盖目标组其他成员和附近散件。穿入台面时提示抬高目标，不擅自移动目标。

超时或无法完成保留 unresolved，可带说明试装。结果按几何摘要、相对变换及算法版本缓存。选择时消费候选索引，靠近时检查具体终态；不在每帧扫描全部姿态分支。通用分支只复用其明确发布的完整实体核定；原装／修正参考姿态重新检查直接配合双件，不能继承未经核定的通过状态。当前全量接口核对及参考姿态几何结果见验收记录。

“全部部件已纳入组合”“当前已知规则下无可用连接”和“正在检索或条件未完成”分别表达。任一状态下仍可移动、拆开及继续探索。

手动档位不自动改变。画质调整与提示只根据持续交互采样，跳过加载、空闲和解释动画的零散重绘；性能不足时保留可点击的切换提示。静止停止重复绘制。减少动画设置会缩短连接及相机动效。几何加载、预览副本、后处理、纹理、解码后的 ImageBitmap、事件监听及 WebGL 上下文随场景切换释放。环境资源与部件均加载完成后才标记场景就绪；加载失败显示重新加载入口，切换场景会取消旧请求并释放晚到资源。

参考目标为 RTX 2080 Ti、1080p、70 部件、高画质持续交互 60fps，P95 不高于 20ms；目标与实测分别记录，不用首次完整 DKP 校验耗时替代交互性能。
