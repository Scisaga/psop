# 原子特征、参数化接口与装配方案

2026-11-06（Asia/Shanghai）。本页落实 [硬件本体 draft.4](hardware-ontology.md) 第 5、7、8、10、11 节，作为 Build、Simulate、Compile 和工作台的共同消费规则。机器定义、可执行范围及输入输出以随实现发布的 Schema 和能力声明为准。

## 1. 知识层次

| 层次 | 可以表达 | 不能由本层直接推出 |
| --- | --- | --- |
| 有限 Feature | 孔壁、轴壁、平面、边界、来源三角面、局部框架与测量 | 螺纹、安装用途、保持或连接成立 |
| 逻辑孔 | 同一孔道的壁段、端口及连通见证；保留原子身份 | 端口数等于孔数、同轴就贯通、允许旋入深度 |
| 安装孔位 | 带功能依据的入口位置、进入方向、作用角色及其底层孔道引用 | 两侧孔位是互不关联的占用资源、当前已经接合 |
| 实体安装位置 | 同一 Part 上的有限柱、定位销等 Feature、作用方向及功能依据 | 圆轮廓就是孔、必须存在独立螺钉、已知保持机制 |
| 几何模式 | 共同测量框架下的孔距、节圆、矩形或其他布局及成员 | 功能接口、获准选孔数量或全部装法 |
| 参考观测 | 固定配置中的齐孔、孔轴有限配合、相向有限区域投影交叠 | 接触状态、支承作用、紧固或装配可达性 |
| Interface／mode | 有机制及角色依据的连接能力、原子成员、互补要求与组合约束 | 选中或完成某次装配 |
| 选择与绑定 | 某一方式下实际选定的成员 S、跨对象角色映射、第三件要求和共同构型 | 全部可选成员都已使用、连接件已存在或已接合 |
| 装配方案 | 引用具体绑定、条件、可用的操作／路径依据与未决项 | 方案已具备路径，或当前已保持、工程和任务均通过 |
| 操作／路径 | 针对具体绑定的进入、作用和解除过程，含框架、起止条件及检查范围 | 孔口向量就是装入方向、终态匹配就是过程可达 |
| InterfaceConnection／状态 | 配置内冻结的具体角色与特征绑定、局部作用、状态依据和派生判断 | 仅列出参与者就形成保持或完成 |
| 显示投影 | 从相同身份与配置派生的高亮、透明、爆炸和示意姿态 | 新的物料、方向依据、装配事件或物理通过结果 |

普通壳面或裸孔只因贴近、同轴或投影重叠而得到的结果，保留为 Feature／参考观测。Interface 至少需要具体机制、本方及互补角色、角色绑定的有限特征、适用条件，以及功能来源或可复验功能结构规则的见证。填入机制名称或 `candidate` 标签不能替代这些依据。

来源只确认安装位置时，应发布已经确认的原子位置和功能声明，同时将机制、选用数量或互补关系分别标为 unknown。这个部分知识记录不等于完整可执行的 Interface/mode；不能为凑齐定义补造机制，也不能因尚缺规则就隐藏全部已知位置。

整块源面面积与参考投影交叠面积分别记录。二者都不能直接称为真实接触面积或承压作用区；作用区还需由具体机制、绑定及适用状态说明。

## 2. 原子身份与分组

阶梯孔的多段壁及环形肩面可以共同描述一个逻辑孔。合并要有有限孔道及拓扑连续依据；两个背靠背盲孔不能仅因同轴而合并。一个通道的两个端口也不增加孔数。逻辑孔不成为新的 Part。

几何模式引用逻辑孔及具体端口，保留原始身份。两侧端盘、壳体安装阵列和不同运动区域分别分析；同一组点可以有多个几何描述，不能因此复制功能接口。源网格仅提供测量框架时，运动区域归属继续标为未确认。

有功能依据的单孔能力可以独立使用，也可以成为参数化接口的可寻址局部角色。面向装配的原子选择对象是安装孔位：它引用有限特征、具体入口、进入方向和底层孔道。一个双入口孔道可以提供两个安装孔位，两个孔位仍共享同一有限通道资源。

例如舵机壳体的四条孔道分别提供 A1～A4、B1～B4 八个侧别孔位。接口引用这八个可寻址成员，并定义选用规则；不把两侧平面分组变成 02／03 两个同名接口，也不为每个双孔子集复制接口。底层几何模式仍可保留两侧测量，浏览时按同一孔道集合与布局聚合，将入口侧作为子项。

几何阵列只描述布局，不规定安装使用数量。安装孔位及接口的功能依据可以来自明确的人工说明；说明原文、作者类型、适用设备／几何修订与推导范围均须固定到输入及证据。不能因为网格单独不能证明功能，就丢弃已有的功能说明；也不能把一条说明扩展为未声明的螺纹、旋入深度、承载或紧固件规格。

安装位置不限于孔入口。实体柱引用自身有限 Feature，hole_ref 和 portal_ref 为空；不能给柱虚构孔道，也不能按空引用统计出一条“共享孔道”。识别必须区别孔内壁与实体外壁，并复核闭合端面及源拓扑。拔模锥面按实际有限锥壁表达；被壳体截切的基部边界不补成完整圆环，不外推完整圆锥体积、干涉或保持。

## 3. 选择规则与开放集合

以下均为规则示例，不是 Microduck 已确认安装许可：

| 明确声明的规则 | 选择空间 |
| --- | --- |
| 完整允许集合为 AB、CD、ABC、ABCD | `S∈{{A,B},{C,D},{A,B,C},{A,B,C,D}}` |
| 任取两至四孔 | `2≤|S|≤4`，共 11 个子集 |
| 至少完整包含 AB 或 CD | `AB⊆S OR CD⊆S`，共 7 个子集 |
| AB、CD 各自必须成对选用 | 仅 AB、CD、ABCD，排除 ABC |

`S={A,B}` 与 `AB⊆S` 不同。只知道 AB、CD 两个合法例子时，其余组合保持 unknown；不能猜测通用数量规则，也不能将未列项一律禁止。规则注明依据、工况、所属维度及集合是否完整。

“同侧至少两个相邻安装孔位”表达为同侧选择，并至少包含一对有依据的邻接成员。邻接由明确的孔位关系或几何规则定义，不是列表序号相邻，也不等于最近邻；矩形短边、长边和对角分别辨认。选择集合含邻接对，不自动证明整个三／四孔组合与任意对端都能安装，仍须共同构型、互补角色和连接件条件成立。

机械、工程及任务条件分别保存。某工程规范要求最少两颗连接件，不等于单孔物理上无法接合；任务指定某孔组也不删除其他有依据的连接能力。AB、CD 分别成立不保证 ABCD 在同一构型下成立；ABCD 成立也不证明任意子集仍满足要求。

`FEATURE / REF` 保留身份，`SELECT` 生成受约束的成员选择，`MATCH` 建立角色与孔映射，`AND / OR` 合并共同要求或保留替代方式，`REQUIRES / EXCLUDE / SHARE` 描述依赖、互斥与实际共用。固定清单、数量范围、锚点和成对条件都只是规则的具体形式。

## 4. 两部件装配查询

`query(A,B,context)` 返回装配方案及搜索范围。context 固定输入修订、起始配置、机制库、允许使用或增添的连接件、环境、已有关系、工程和任务条件。不得无边界地发明粘接、钻孔、螺钉或适配器，继而宣称穷尽全部装法。

每项方案保留：

1. 一个或多个有依据的接口方式、角色、选孔子集与对端映射；
2. 已绑定的真实参与者，以及尚未绑定的连接件／承接角色要求；
3. 所有关联共享的一份构型，包括各 Part 位姿与内部活动框架的 q；
4. 有限作用区域、联合几何及占用条件；
5. 适用的接近、对齐、进入、接合、保持、检查和解除阶段；
6. 机械、工程、任务、完成四个维度的结果、来源、假设及未决项；
7. 知识、选择、映射、位姿、路径与机制搜索的完整性和停止原因。

刚性孔组的全部映射必须由同一个 proper SE(3) 变换满足；不允许逐孔单独配准或任意缩放。有内部运动时，所有关系共享一致的 q 与 Frame 生成链。孔距、轴向、端口朝向、有限孔段、作用面及连接件共同检查，不能只看中心距离。

对称阵列保留多个可能的旋转映射；镜像、翻面与轴向不能跳过手性和角色条件。几何等价不自动成为工程或任务等价，也不因不同于来源 qpos0 就被判为误装。

## 5. 多条路径、并用与状态

一项四孔夹紧关联可以包含 p1 至 p4 四条局部路径；两个 Part 也可以有多项独立连接。经适配器连接还可能包含 A—C、C—B 两项关系。拆分按机制和作用范围确定，不按 Part 对或孔数唯一化。

S 是选定绑定，不是已经接合的孔集合。各路径独立保存状态及证据；只有方式明确要求全部选中路径完成时，才使用 `complete(C)=AND(complete(p), p∈S)`。部分路径已经形成的作用继续参与机械图，即使整组尚未完成或任务错误。

同一个接口可以被多个连接分别选择，例如 AB 接 X、CD 接 Y，不设置全接口统一 `capacity=1`。共享一个孔时，检查实际通道区段、作用区和参与者：一根螺栓贯穿多层与两根螺栓争用同一区段不同。未知并用条件不默认允许或禁止。

参数化 Interface 定义身份保持稳定；已发布的具体连接冻结选孔、映射、方式和参与者。改变这些绑定创建新连接身份或新快照，保留未拆路径的显式连续性依据，不能继承旧整体通过结果。

## 6. Simulate 的试装边界

Build 应交付安装孔位、组合规则与已有标准装配的具体对应关系。参考关系固定在来源 Configuration 中，保留双方孔位映射、共同参考位姿、机制说明、连接件角色和来源证据。无需等 Simulate 执行后才识别标准安装关系；该关系也不将这些孔永久限定为只能连接原来的对端。

安装关系可跨越两段孔壁之间的间隙。Build 应结合已声明的装配关系，复核孔轴、孔距、方向和有限范围，保留间隔测量及未绑定连接件要求；不能把“孔壁近接”阈值当成全部紧固安装的判据，也不能通过扩大近接阈值伪造已接合状态。

建议查询可以按工程和任务要求排序或筛选；自由试装须能够评估用户指定的其他组合。规则清单不是物理锁。未知组合进入明确假设的评估分支；缺少能力或资料时报告未评估，不能用动画宣布接合成功。

终态相容与从当前状态可达分别判断。普通刚体碰撞不能独自证明一个依赖弹性变形的卡扣无法接合；缺变形模型报告不支持。解除方式也不默认等于装配路径反向。

舵机壳体与输出区域需要各自的运动归属。外部部件若装在输出接口上，应随输出 Frame 运动；不能将整个舵机与外部件理想固定后，再用该结果证明真实紧固。跨活动区域的连接可能限制内部运动，须保留实际机械作用并另判任务符合性。

## 7. 当前实现及验收

source-model/1.3 冻结来源几何、逻辑孔、几何模式和参考观测的分层。1.4 在此基础上摄入带摘要的装配知识说明，发布安装孔位、组合规则、参考安装映射和有几何依据的槽记录。1.5 增补上方四孔及左右大腿实体锥形几何；其中小柱功能曾错误沿用用户确认口径，在 1.6 中明确纠正为项目推断。1.6 补入圆内开口、有限变半径腔、逐对连接审查与补全示意。1.7 新增柱孔有限配合及补全件 usage，按实际配合、定位与保持分工组织，当前 1.8 新增参考连接件的显式装入假设与有限方向核对；旧 1.0～1.7 保持原字节。Microduck 安装说明中的用户确认与项目推断分别限定范围，标准孔位映射还要由参考模型复核；说明不等于制造商工程认证或模拟执行结果。

连杆上方四孔为直径约 2.2 mm、节圆直径约 12 mm 的几何布局。当前按功能位置和已核验的完整入口定位，其他侧入口继续作为几何记录；用户未确认双向八个功能位置，也未给出最少选用数量。附近舵机阵列与其在来源 qpos0 相差约 45°，不能逐孔独立旋转来伪造共同参考映射；也不能把该配置的相位差当作其他构型的装配禁令。源 hinge 不足以证明输出 Frame 已核定。

大腿每两根带拔模斜度的实体柱与同台舵机壳体 B2／B3 孔配对，组距约 16 mm；来源位姿下有限插入约 2 mm，孔径约 2 mm、插入段柱径约 1.80→1.59 mm。pin_hole_fits 保留共同配置、双方原子身份、有限范围及间隙；这是安装定位用途的几何支持和项目推断，不能称为用户确认。源模型有间隙，无过盈或倒扣见证；轴向保持、真实公差、材料和承载均待查。两成员参考分组不定义最少选用数量、允许子集或实际接合集合。

外侧 Ø5.5 mm 圆洞及环形／台阶轮廓用途 unknown。与舵机圆盘共轴不使其成为主固定接口、螺钉孔或轴承座，也没有依据称为装饰。单纯对齐、有限面投影和源 hinge 不能补成紧固、碰撞通过或已保持。

已知孔位、已知参考安装、尚未分析的槽以及未实现的物理能力分别展示。不能用统一“机制未确认”空状态抹掉已有知识。旧 1.1／1.2 的自动几何接口分类不沿用为新功能资格，1.3 的原空功能数组也不被原地改写。

孔位默认高亮其孔壁和当前入口，阵列用细线或节圆辅助定位。拓扑支持三角面用于复核来源，不能直接成为默认选中区域或作用面；同一批支持面也不得由端口及阵列重复绘制。改变入口侧时明确强调对应入口，避免将两侧圆环一律穿透显示为相同对象。

源模型中的完全重合面可造成显示深度冲突。工作台可对材质使用微小深度优先级和合适裁剪范围；这种显示修正不得移动源顶点、改变源位姿、删除相邻部件或重排证据三角面，也不成为接触或装配事实。

共享选择／匹配引擎用于声明范围内的有界组合与刚性孔组推理。合成夹具验证组合、共同位姿、对称、未绑定角色和局部状态规则；不能将合成规则赋给 Microduck，不能将静态候选推理称为物理、路径或工程验收。

验收至少覆盖：阶梯孔不重复计数；同轴盲孔不错误贯通；八个安装孔位关联四条共享孔道；同侧邻接与对角不混淆；标准双孔参考映射跨间隙仍可追溯；输入说明与映射篡改被拒绝；槽记录有有限边界和源拓扑；四种集合规则不混淆；开放清单保留 unknown；逐孔能配准但没有共同位姿时失败；保留对称映射；同接口分开使用及共享孔的真实占用；部分接合不等于整组完成；缺连接件不虚构 Part；活动区域不被误锁；搜索不完整不报告不存在装法。

Build 生产带证据的原子结构、接口定义和条件；Simulate 组合并评估具体方案、路径与状态；Compile 保留这些层次和多维标签，学习到的建议仍经同一机制及动作链检查。工作台按实际知识层展示、查询和定位。

## 8. 逐处连接还原与补全件

连接审查以实际参考装配中的部件对及完整参与链组织，不以检测到的孔、柱或面数量验收。逐项区分定位、导向、保持、传递转矩及允许运动，记录双方作用位置、中间件、适用范围、来源与缺项。同一部件对可有多种机制或多条路径；第三件及替代解释均应显式保存。

圆内轮廓、有限内腔及两侧入口分别寻址，贯通需要有限壁和共享边见证。近邻开口、共轴或源壳体整体拓扑相连不能代替孔道连续性。有限面重叠继续是辅助观测，不能承担“靠什么固定”的解释。源模型简化了舵机端部时，壳体、输出端和随动端归属继续待核定。

原件缺少标准件网格时，允许按有依据的规格参数化补建并固定来源；未确认规格或实际使用的组件明确标为补全示意，使用独立 synthetic 身份和 not_confirmed BOM 状态。1.7 的 reference_connector 仅表示已有参考安装路径中的未绑定连接件，unverified_alternative 表示尚未核实的替代示例。后者不进入当前保持角色，默认不显示；厂商轴心螺钉／压盖在本设备中仅属此类，不能因显示它们就生成固定状态或实际物料。推断的功能依据不标作用户确认。

1.6 固定所有部件对的参考广相筛查及候选审查记录，明确包围范围只是筛选；1.7 延续这些记录并纠正大洞与轴心示意件的用途资格。工作台优先展示可复验的局部配合、作用分工和缺项；未核实替代解释单独查看，来源实例与各类示意分别计数。示意沿轴展开只为观察，不是装拆路径验证。筛查覆盖、还原完整性、机械与工程验收分别报告。详细过程和大腿样板见[完整连接还原](../build/connection-reconstruction.md)。

## 9. 规则、绑定、操作和显示的一致性

以下为三技能及工作台的通用约束。1.8 已对参考连接件实现受限的有限方向／区段一致性核对，尚未实现完整物理与连续装配路径检查；具体缺项见[连接还原与验收](../build/connection-reconstruction.md#方向与有限路径的核对)。

**按作用定义模式，按绑定实例化连接。** 一个模式规定角色、可用成员、选择谓词、互补要求、定位／保持／允许运动条件及适用依据；一个具体方案再绑定参与者、S、角色映射、中间件和共同配置。几何模式、选择规则、实际绑定及操作规则分别保存，不能用同一组点、同一个部件对或同一张界面卡代替它们。一个特征可参与多个有不同作用的模式；位置相近不使它们自动合并。柱孔配合可在其范围内声明一一映射，穿层螺栓则可在同一路径关联多个孔和中间件，不能把所有连接统一为两个对象的一对一孔映射。

**方向带有角色和框架。** 几何轴线、表面法向、孔口进入方向、实体柱基部到端部方向、连接件自身轴线、某操作的接近／装入方向，以及爆炸显示偏移是不同量。每个量按自己的定义、Frame、单位和适用配置解释。孔口用于标识从某侧进入本孔，不自动给出连接件由谁穿向谁；列表顺序、最近孔口、全局正负轴或壳体／支架角色名称都不能独自决定头尾和装入方向。

**方向与尺寸具有独立的依据范围。** 知道孔位对应，不等于知道装入侧、头部承座、受力位置、螺纹承接段、有效长度或物料身份。来源只支持其中几项时，其余分别 unknown；厂商通用例子、参考路径角色和 illustrative 标签都不补足缺项。需要展示尚未核定的方向时，作为显式假设与其他可行解释分开，不写成来源事实或已执行操作。

“路径”也须注明含义：有限孔道描述源几何连通；紧固路径要求或 role_paths 描述角色／作用链；操作运动路径描述配置如何随过程变化；爆炸轨迹只描述显示偏移。这四者不能互作通过依据。“两条紧固路径，连接件未绑定”既不表示已有两颗螺钉，也不表示已算出两条无碰撞装入轨迹。

**图形必须满足自己声明的有限关系。** 显式采用某种装入假设后，示意件的头部承座、有限杆段和目标位置仍须互相一致。轴线共线但杆段背离目标或未到达目标，不能称为表达了该路径。沉头、内侧装入、盲孔、螺母、多层件、旋转锁止、弹性卡扣按各自机制检查，不能套用“头必须在外、杆直线穿两孔”的固定模板。末态几何一致、连续路径可达、保持成立及工程合格仍分别判断；未知尺寸不能为了让图形看起来闭合而被当成实物规格。

**证据落实到结论，状态落实到检查。** 对应、方向、定位、轴向保持、转矩传递、活动归属和承载分别说明来源或推导、适用对象／配置、检查结果和未决条件。一份来源出现在同一审查中，不等于支持该审查的每个结论。未建模不是失败，局部成立不是整体通过；定位可以有几何支持，同时保持 unknown、连续路径 unavailable、工程未评估。源网格中未表达的螺纹、摩擦或变形，不外推为实物不存在。

**验证不能只有重放。** 来源摘要与确定性重放保证字节及推导可重复，不能发现生成器和重放器共同重复的方向错误。还需针对声明关系核对独立几何残差、有限区段与角色条件，并用换入口、交换对象顺序、共同刚性变换和跨机制反例检验规则。相同结论的对象顺序变化不得改变实际物理方案；若角色或装入假设改变，则显式生成另一方案而不是悄悄翻转向量。显示偏移不得反馈到这些判断。

面向人的阅读顺序是“本件有哪些能力 → 本次／参考安装绑定了谁和哪些位置 → 采用或假设什么操作与保持方式 → 哪些判断已经成立”。相同绑定只保留一处主详情，选择规则与实际映射使用不同的标记；具体呈现及当前实现差距见[工作台消费规范](device-workspace.md#接口面板的通用消费规范)。
