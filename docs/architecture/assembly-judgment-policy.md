# 装配判定与设计保真

2026-11-11（Asia/Shanghai）。用户确认的高优先级规则，适用于 Build、Simulate、Compile、装配研究、数据标注及相关提示词。

> **不能把刚性网格交集直接作为装配的否决条件，也不应为了消除交集就认定需要移动或修改原设计。**

本规则优先于仓库旧文档、技能和任务提示中“有交集即拒绝”“只有零交集才能装配”及“减少交集即可认定修正正确”的表述。历史包、原始测量和实际运行记录保留其版本与原义。

## 判定与操作

刚性求交描述指定网格和位姿下的几何关系。实际部件可以通过弹性让位、过盈、预紧、软接触及制造或装配补偿形成正常连接；自由状态外形、装配受约束状态和计算网格需要分别解释。

- 对已有原装关系的微小接触重叠，装配编辑默认允许，并保留体积、位置等测量记录。缺材料参数、变形求解器或应力结果，不直接构成禁止虚拟装配的理由；力学分析按任务需要另行开展。
- 允许使用可配置的重叠体积、局部深度及接触区域阈值处理微小交叠，并按连接机制调整。数值计算精度与工程可接受重叠分别表达；不把某次观测值写成所有设备的统一阈值。
- 对明显错位、错误尺寸、无关部位的实质穿入或资源冲突，按具体证据给出处置。刚性求交的正体积本身不足以证明这些情况。
- 刚性几何检查、装配操作资格、力学与工程验证分别记录。允许参考装配不需要将求交的 `interference` 改写为 `clear`；力学未计算保留为未计算，不自动解释成装配失败。
- 不凭交集编造具体材料、允许应变、过盈量、预紧力或作者意图。缺少这些数据不抹掉已有的原装关系与可操作参考。

例如，已有原装关系中的约 `0.00305 mm³` 微小接触交叠不应仅因体积大于零而禁用连接；该值是讨论实例，不是通用阈值。

## 原设计与修正配置

原始网格、来源位姿、装配关系和用户选择的配置应保留。存在重叠时，先考虑模型状态与连接机制，不能自动认定上游设计错误，也不能为了通过刚性检查而添加间隙、移动、缩放、切削或改写源几何。

有独立定位、尺寸、坐标映射或设计依据支持参考数据错误时，可在用户已授权的任务范围内合理修正，不重复要求许可。修正保存为单独的工程推断配置，记录依据、调整范围及受影响关系；交集减少只是几何变化，不能独自证明设计正确。相关连接应采用一致配置并分别核对功能条件，不因局部重叠更小自动替换默认配置。

已有“修正配置”的历史名称、测量及发布身份继续保留；其通过指定有限约束，不等于原设计的预紧或补偿意图已被否定。

## 技能、提示词与监督

- 仓库常驻提示词为 [AGENTS.md](../../AGENTS.md)，三个技能入口保留本规则并链接本文；更细的执行合同不得反向恢复几何一票否决。
- Build 保留求交观测、来源关系和机制解释，区分已发布刚性筛查范围与装配资格，不因原装存在交集就删除关系或强制改设计。
- Simulate 将微小可接受重叠用于操作判定；参考连接可保留原始求交结果，不把完整材料库或有限元求解作为装配编辑前置条件。
- Compile 分开标注几何交集、装配关系与力学状态。刚性求交重叠、未建模变形或来源偏置不能直接制成“不可装配”“误装”或“设计错误”的负例；消除交集后的姿态不自动成为唯一正确答案。

## 当前实现

共享执行策略为 `psop.assembly-policy/1`，操作判定为 `psop.assembly-assessment/1`。Build /3 和 Simulate 使用[同一判定函数](../../skills/psop-build/scripts/assembly-judgment.mjs)。`closed-source-solid-interference/2` 保留原始语义；允许操作后仍保存实际 `interference` 或未计算状态。

新方案默认来源原装构型。几何协调为可选的工程推断；切换构型设置不会移动已有方案，“按此构型还原”才执行整机还原。两个构型中的全部参考关系由同一套全局位姿生成，不根据单条展示文案决定是否生成分支。旧方案根据已存设置、参考还原报告或一致的连接引用推断配置，保留现有位姿与连接。

原装参考及合格接口接触允许操作并记录；较大的原装重叠也不额外要求确认。错误成员、资源冲突及闭环不一致仍按独立证据阻止。连接终态低于台面时，将参与连接的两个组合共同向上平移到最低点高于台面 `0.2 mm`，不改变任何内部相对位姿、来源几何或参考构型；预览展示抬升后的完整结果，连接与抬升保存为一次可撤销操作。已有足够高度时保留目标组合的位置。抬升后的双方仍检查组合间及与周围部件的关系。无关部件只有新增或加深的实质穿入见证才构成阻止理由；超时、开放网格、缩放未支持或缺少材料不独立否决虚拟连接。

默认 `0.01 mm³` 仅为接触记录显示筛选；默认 `0.1 mm` 用于新增或加深的无关障碍采样深度比较，均可按方案配置，不是制造公差。数值接触精度仍为 `3e-7 m`。深度使用有限源表面采样与三角距离 BVH，提供坐标系、交集分量和源三角见证，明确不是精确最大穿入深度。未采到障碍不构成无碰撞完备证明。

Build 匹配策略 /3、固定落座策略 /3、兼容索引及分片 /2 将操作资格与刚性观测分别发布。固定落座 /3 使用 `finite-interface-contact-regions/1`：从实际选中成员的有限圆柱或锥面生成接触包络；仅当源表面采样点同时位于该包络之外、并有超过方案深度阈值的实体穿入见证时，排除通用候选的该方向。记录源网格、坐标系、三角面、穿入深度及距包络的距离，不将交集体积直接作为排除依据。发现独立障碍见证即可结束筛查；未发现仍不构成完整无碰撞或力学认证。

来源原装关系不受上述通用候选筛查否决；接口区域内的过盈、预紧或软接触继续记录并允许。旧固定落座 /2 及历史包按原版本语义验证，不改写其测量与发布身份。Simulate 对旧包的通用候选补做同一接触区域校验，并在实际连接提交时复核，不能仅因端点参与连接就将整件的任意穿入都认定为合格接触。[Compile 监督合同](../../skills/psop-compile/references/assembly-supervision-contract.md) 分开规定几何、关系、操作与力学标签。执行范围与验收见[优化交付记录](../assembly-judgment-optimization.md)。

旧包补查复用完整包验证通过且双件源 SHA 一致的已有刚性观测，重新检查选中接触区；源网格的三角距离索引缓存于各自局部坐标系，刚体变换时转换查询点。快速补查不重新计算交集分量，诊断中明确记录；用户请求详细测量时重新求交并计算分量，不把快速筛查伪记为完整测量。

Simulate 按参与实例、接口、成员及资源绑定归组，再按实际成员映射和相对位姿合并等价机制假设；方向变化保留为独立姿态，来源原装的不同关系不合并。展示和计数使用装配姿态，Build 发布的原候选及其紧固件条件仍保留。螺钉旋入、穿孔螺栓等未确认的紧固方案在详情中分别说明；缺少螺纹或螺母规格不禁止虚拟试装，也不因点击试装就认定某个紧固方案成立。服务端从已校验的候选重新归集等价假设，保存 `mechanism: unresolved`、`mechanism_status: unconfirmed` 及全部 `mechanism_options` 来源和待确认条件，重载、复制、撤销与重做均保留；不能把这些假设标成已确定的紧固机制。

候选对象目录直接读取包中已发布的部件配对索引，按来源部件预建邻接表；选中时只读取本组接口和资源占用，不遍历全部方向做几何复核。接口详情按需读取静态成员关联；靠近或选定某个目标后，仅复核该目标的候选方向，预览和提交继续检查当前场景。目录及 `potential_connections` 场景状态只表达潜在关系（`qualification: pending`），不代表几何通过或当前操作获准。候选目录读取与目标复核分别呈现进度和可重试错误；目录请求有 10 秒截止时间，其他读取有 45 秒截止时间，自动组装单独保留 190 秒预算。

固定源几何观测另存于本地内容寻址缓存，绑定源 SHA、R/T、诊断与接触区参数、源观测及实际计算文件摘要；算法变化、请求变化或记录校验失败均重新计算。仅缓存已完成的 `clear/interference` 观测，不缓存未计算或超时结果，不缓存场景操作资格；资源、构型、策略与现场障碍仍分别复核。缓存写入采用临时文件原子替换，下一次启动可复用已完成的记录，包中来源几何与原装位姿保持不变。

复合卡扣、有限承座等接口通过 `finite-source-interface-substitution/1` 补全可替换候选：已有配合提供互补角色和安装位姿，替换端必须在同一个正旋转刚体变换下匹配全部选中成员、有限源三角面、法向及圆柱/锥面尺寸。比较不依赖左右名称、来源部件身份或原装配对名单；仅有镜像外观、相同包围盒或单个孔轴重合不足以通过。有限面使用双向源顶点及三角中心距离和面积复核，记录比较精度与有限几何范围，不宣称完整 CAD 等价或力学认证。新候选保留来源配合、接口等价映射和证据，作为试装关系保存，不伪记为原装关系。

新 Build 的接触区域策略发布独立的 `indexes/interface-adaptations.json`；验包重算并核对。历史包由 Simulate 在工作线程中派生同一索引，按包摘要和分析文件摘要缓存，选择时直接查询邻接关系。实际目标姿态、接口资源及现场障碍仍在复核和提交时检查；有限面接触区域不能无限延伸到接口之外。尚未建模的接口机制继续保留未知状态，索引范围不宣称覆盖所有物理装法。

四成员包覆承座另行记录有限接触假设：一对相向定位壁、垂直落座面及同向曲面承托必须在同一正旋转刚体位姿下满足定位间距、杯口宽长、壁面长度与杯口相位、承托深度及有限投影接触条件。比较聚合每个成员的实际选中源三角面，不能因曲面分片数量或采样重心不同就漏掉候选。此类结果写入 `interface_fit_hypotheses`，不冒充严格曲面等价；保存成员映射、定位尺寸、双向采样曲面差异及未核定条件。接触范围限于杯口的有限宽长和原始源几何在承托侧的深度；范围内的重叠照实记录，范围外的实质穿入仍按独立障碍处理。界面标注“包覆曲面待核定”；允许虚拟试装不认证曲面贴合、弹性让位、保持或承载，不改动原几何和原装位姿。

前端将空候选和选择目标保持稳定，画布只在实际选择、目标、位姿或视角变化时更新；统计回报不得触发选择更新与重绘反馈循环。连接图示使用异步 GPU 像素读取，在等待 GPU 前恢复共享渲染器状态，已离开的卡片忽略迟到结果。

## 工程依据

- [PTC Creo View：干涉检测类型](https://support.ptc.com/help/creo/view/r12.0/fr/creo_view/adapter_install_config_guide/Config-Batch-Interference/ClashbatchAdapterWorking/Selecting_Interference_Detection_Types.html)：允许将可接受重叠体积设为大于零，用于软质或橡胶零件。
- [SOLIDWORKS：干涉检测](https://help.solidworks.com/2021/english/SolidWorks/sldworks/c_Interference_Detection.htm)：压配及螺纹紧固件等重叠可按设计忽略。
- [BASF：卡扣设计](https://ultrasimweb.basf.com/snapfit/blog/introduction/)：用挠度、材料应变与装配力评价弹性连接。
- [Abaqus：接触初始化](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEITNRefMap/simaitn-c-genlcontinitializationstd.htm)：区分无应力初始调整与产生应力、应变的过盈配合求解。
- [Autodesk：补偿几何](https://help.autodesk.com/cloudhelp/2019/ENU/NTFABLS-Utility-Help/files/GUID-DB71FB6D-60F3-4093-9033-D7D0E3A3CF63.htm)：可预先改变几何，使制造变形后接近目标形状；这一机制不直接证明某个具体部件的作者意图。
