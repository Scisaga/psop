# 装配判定与设计保真

2026-11-11（Asia/Shanghai）。用户确认的高优先级规则，适用于 Build、Simulate、Compile、装配研究、数据标注及相关提示词。

> **不能把刚性网格交集直接作为装配的否决条件，也不应为了消除交集就认定需要移动或修改原设计。**

本规则优先于仓库旧文档、技能和任务提示中“有交集即拒绝”“只有零交集才能装配”及“减少交集即可认定修正正确”的表述。历史包、原始测量和实际运行记录保留其版本与原义。

## 判定与操作

刚性求交描述指定网格和位姿下的几何关系。实际部件可以通过弹性让位、过盈、预紧、软接触及制造或装配补偿形成正常连接；自由状态外形、装配受约束状态和计算网格需要分别解释。

- 对已有原装关系的微小接触重叠，装配编辑默认允许，并保留体积、位置等测量记录。缺材料参数、变形求解器或应力结果，不直接构成禁止虚拟装配的理由；力学分析按任务需要另行开展。
- 允许使用可配置的重叠体积、局部深度及接触区域阈值处理微小交叠，并按连接机制调整。数值计算精度与工程可接受重叠分别表达；不把某次观测值写成所有设备的统一阈值。
- 对明显错位、错误尺寸、无关部位的实质穿入或资源冲突，按具体证据给出处置。刚性求交的正体积本身不足以证明这些情况。
- 刚性几何检查、装配操作资格、力学与工程验证分别记录。允许参考装配不需要将求交的 `interference` 改写为 `clear`；力学未计算保留为未计算，不自动解释成装配失败。
- 不凭交集编造具体材料、允许应变、过盈量、预紧力或作者意图。缺少这些数据不抹掉已有的原装关系与可操作参考。

例如，已有原装关系中的约 `0.00305 mm³` 微小接触交叠不应仅因体积大于零而禁用连接；该值是讨论实例，不是通用阈值。

## 原设计与修正配置

原始网格、来源位姿、装配关系和用户选择的配置应保留。存在重叠时，先考虑模型状态与连接机制，不能自动认定上游设计错误，也不能为了通过刚性检查而添加间隙、移动、缩放、切削或改写源几何。

有独立定位、尺寸、坐标映射或设计依据支持参考数据错误时，可在用户已授权的任务范围内合理修正，不重复要求许可。修正保存为单独的工程推断配置，记录依据、调整范围及受影响关系；交集减少只是几何变化，不能独自证明设计正确。相关连接应采用一致配置并分别核对功能条件，不因局部重叠更小自动替换默认配置。

已有“修正配置”的历史名称、测量及发布身份继续保留；其通过指定有限约束，不等于原设计的预紧或补偿意图已被否定。

## 技能、提示词与监督

- 仓库常驻提示词为 [AGENTS.md](../../AGENTS.md)，三个技能入口保留本规则并链接本文；更细的执行合同不得反向恢复几何一票否决。
- Build 保留求交观测、来源关系和机制解释，区分已发布刚性筛查范围与装配资格，不因原装存在交集就删除关系或强制改设计。
- Simulate 将微小可接受重叠用于操作判定；参考连接可保留原始求交结果，不把完整材料库或有限元求解作为装配编辑前置条件。
- Compile 分开标注几何交集、装配关系与力学状态。刚性求交重叠、未建模变形或来源偏置不能直接制成“不可装配”“误装”或“设计错误”的负例；消除交集后的姿态不自动成为唯一正确答案。

## 当前实现

共享执行策略为 `psop.assembly-policy/1`，操作判定为 `psop.assembly-assessment/1`。Build /3 和 Simulate 使用[同一判定函数](../../skills/psop-build/scripts/assembly-judgment.mjs)。`closed-source-solid-interference/2` 保留原始语义；允许操作后仍保存实际 `interference` 或未计算状态。

新方案默认来源原装构型。几何协调为可选的工程推断；切换构型设置不会移动已有方案，“按此构型还原”才执行整机还原。两个构型中的全部参考关系由同一套全局位姿生成，不根据单条展示文案决定是否生成分支。旧方案根据已存设置、参考还原报告或一致的连接引用推断配置，保留现有位姿与连接。

原装参考及合格接口接触允许操作并记录；较大的原装重叠也不额外要求确认。错误成员、资源冲突、闭环不一致及台面穿入仍按独立证据阻止。无关部件只有新增或加深的实质穿入见证才构成阻止理由；超时、开放网格、缩放未支持或缺少材料不独立否决虚拟连接。

默认 `0.01 mm³` 仅为接触记录显示筛选；默认 `0.1 mm` 用于新增或加深的无关障碍采样深度比较，均可按方案配置，不是制造公差。数值接触精度仍为 `3e-7 m`。深度使用有限源表面采样与三角距离 BVH，提供坐标系、交集分量和源三角见证，明确不是精确最大穿入深度。未采到障碍不构成无碰撞完备证明。

Build 匹配策略 /3、固定落座策略 /2、兼容索引及分片 /2 将操作资格与刚性观测分别发布；历史策略和包不改写。[Compile 监督合同](../../skills/psop-compile/references/assembly-supervision-contract.md) 分开规定几何、关系、操作与力学标签。执行范围与验收见[优化交付记录](../assembly-judgment-optimization.md)。

## 工程依据

- [PTC Creo View：干涉检测类型](https://support.ptc.com/help/creo/view/r12.0/fr/creo_view/adapter_install_config_guide/Config-Batch-Interference/ClashbatchAdapterWorking/Selecting_Interference_Detection_Types.html)：允许将可接受重叠体积设为大于零，用于软质或橡胶零件。
- [SOLIDWORKS：干涉检测](https://help.solidworks.com/2021/english/SolidWorks/sldworks/c_Interference_Detection.htm)：压配及螺纹紧固件等重叠可按设计忽略。
- [BASF：卡扣设计](https://ultrasimweb.basf.com/snapfit/blog/introduction/)：用挠度、材料应变与装配力评价弹性连接。
- [Abaqus：接触初始化](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEITNRefMap/simaitn-c-genlcontinitializationstd.htm)：区分无应力初始调整与产生应力、应变的过盈配合求解。
- [Autodesk：补偿几何](https://help.autodesk.com/cloudhelp/2019/ENU/NTFABLS-Utility-Help/files/GUID-DB71FB6D-60F3-4093-9033-D7D0E3A3CF63.htm)：可预先改变几何，使制造变形后接近目标形状；这一机制不直接证明某个具体部件的作者意图。
