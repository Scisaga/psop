# 轴承内外圈与喙部轴颈参考接口修正

日期：2026-11-08。此次针对全部 14 个来源轴承实例检查内圈、外圈接口，沿用 Build `source-model/1.15` 合同。

后续 `2.0.0-capabilities.3` 已用有依据的最小参考平移消除下述头部约 0.2 mm 错位，默认显示修正配置，见[合理修正记录](reference-assembly-repair.md)。本文保留 `capabilities.2` 原始配置的测量与发布记录。

## 原因与修改

原输入已为 14 个轴承保留了 28 个内外圈接口。工作台的原装配页却按“是否已存在 Connection”筛选，因而将头部默认轴承的两项接口、头部偏航轴承的外圈接口隐藏。喙部与头部默认轴承之间的具体参考连接也未登记。

现将原装配视图改为保留全部有依据的功能接口，单纯的几何布局假设仍在几何及候选视图中。接口没有原装配对端时明确显示待确认，不生成虚构连接或已用状态。轴承原有 Interface 和 member ID 均保留。

喙部补充“左侧轴承轴颈安装接口”，包含 Ø10、约 2.7 mm 的有限轴颈，以及 Ø12、约 0.3 mm 的短台阶和真实环形肩面。轴颈与内圈的参考连接只选择径向配合成员，未把肩面标成已落座。

| 参考关系 | 依据及状态 |
| --- | --- |
| 喙部左侧轴颈 → 头部默认轴承内圈 | 用户补充原装配关系，双方实测约 Ø10；qpos0 轴线偏心约 0.2 mm，轴向落座仍待核对 |
| 头部默认轴承外圈 → 头部下壳部分承座 | 实测约 Ø15，参考配置中同轴，有限轴向范围重叠；不声明完整包围或轴向保持 |
| 头部默认轴承外圈 → 电机支架部分承座 | 实测约 Ø15；参考配置中偏心约 0.2 mm，保留为待核实承座关系 |

已有两处头部横滚轴承外圈的参考配置冲突继续保留。头部偏航轴承外圈仍没有足够依据确定原装配对端，接口和端面照常保留。其余轴承原有的内圈轴颈、外圈承座及端面参考关系保留原义。

这些修正不移动来源实例，不更改 STL，不声明实际间隙、过盈、防脱或工程通过。跨件几何候选仍为 9,796 条，未被原装配白名单缩小。
