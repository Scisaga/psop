# PSOP 统一工作台：界面与交互设计

## 参考与方向

用户指定 [Mayra](https://scisaga.cc:233/scisaga/Mayra) 的精细程度。参考其固定状态栏、紧凑导航、单层面板、独立滚动区、相邻预览与诊断，以及统一按钮和状态反馈；没有复制其人物资产、业务代码或游戏功能。对照源码提交为 `595c1ec8c7f5fa25d8971e3f679a687e89ab5d3a`。

设计采用 `frontend-design` 技能的定向设计与截图复核流程。主体是当前设备知识包中的真实模型、知识和原文证据。界面保持安静，结构与控件承载信息；设备工作区管理版本与三个技能的上下文。

## 视觉约定

| 用途 | 值 |
| --- | --- |
| 工作面 | 雾白 `#f4f7f7` |
| 内容面 | 白 `#ffffff` |
| 主文字 | 石墨 `#23363b` |
| 次要文字 | 灰青 `#7b8b91` |
| 分割线 | `#dfe7e8` |
| 主要交互 | 矿物青 `#147d83` |
| 选中背景 | `#e5f2f1` |

字体使用本机 Segoe UI Variable 与微软雅黑，资源不依赖外部字体或图标 CDN。圆角按层级使用：小控件 4–6px、弹层 8–10px；主要工作区以分割线组织，不叠加无语义卡片。

## 空间组织

```text
工作区选择 | 设备与版本上下文、全局检索
共享知识   | 模型结构 | 3D 场景 | 对象知识与证据
三个技能   | Build / Simulate / Compile 专用工作区
           | 能力状态、输入版本与产物引用
```

3D 视口占据主要剩余空间，结构树与详情各自滚动。工具贴近作用区域；爆炸、透明、剖切等仅改变浏览状态。窄屏保留导航图标，视口与详情纵向排列。

## 数据诚实性

有证据的几何与来源使用真实数据；未完成的本体实例、接口与工程规格显示具体空状态。派生显示颜色不作为材料事实。来源定位必须能回到原件，不用一段预设说明替代实际文件。

加载、错误、无结果、未映射和只读状态各有明确反馈；浏览器截图用于发现小字、低对比度、遮挡、重复信息和滚动错误。动效主要解释用户操作，尊重系统减少动画设置。

## 设备工作区与版本

工作台是通用软件，一个设备工作区可以登记多个不可变 DKP 快照。侧栏选择设备，版本选择器切换该设备的知识；三种能力入口共享当前设备与版本，页面链接记录 workspace、snapshot 及对象或来源定位。切换上下文会清理旧对象和展示状态，异步读取通过取消机制隔离。

Build 页面显示后端登记的真实包标识、版本、摘要、来源数量与能力声明，不再使用构建进度回放。知识读取来自 DKP 查询接口，前端不从原始 ZIP 维护另一套知识。

Simulate 的装配、场景与视图、模型测试，以及 Compile 的语料、实验、模型和评估使用同一工作台框架。尚未接入的执行服务显示明确空状态，不生成虚构会话、训练指标或可执行按钮。来源模型的爆炸展示仍属于只读浏览。
